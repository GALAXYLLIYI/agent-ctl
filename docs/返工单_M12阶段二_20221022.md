## 返工三处（**都是真问题，不是口味**）

### 返工① ★ 判据 ③「注入自证」**语义反了**，而且**恒真**

现状（`tests\_P2_M12_等待合并_判据.py:146-174`）：

```python
if a.inject:
    core_not_waiting = True      # ← 伪造「core 不再等第二遍」
ok_merge = core_not_waiting and not_slower and ran
...
if a.inject:
    rec("③ 注入自证：假账必须被抓出（本条必须红）", not ok_merge, ...)
```

**主控实测的问题**（两个，都要改）：

1. **③ 在注入模式下红，恰恰说明假账被「接受」了**（`ok_merge=True` ⇒ ③ 的 `not ok_merge` = False = 红）。
   ⇒ 「假账必须被抓出」这条断言，**实际测的是「假账被接受」**。语义反了。
2. **③ 是恒真的**：在「合并未实现」的状态下（core 真的还在等 321ms），
   注入分支同样把 `core_not_waiting` 伪造成 True，`not_slower` 成立（端到端 1700 ≤ 护栏 1770）、
   `ran` 成立（code=8）⇒ `ok_merge=True` ⇒ **③ 照样红**。
   ⇒ **③ 不证伪任何东西**：它无论合并实现与否都红。
3. 另外，注入模式下 ② 的 why 文案写着
   「端到端并没有真的降到基线以下（实测 1488.2ms）」—— 可 **1488.2 < 1682，是降了的**。
   ⇒ 这句话**自相矛盾**，也说明注入的**方向**和文案对不上。

**要求改成**：

- `--inject` 伪造的是**端到端**（伪造成「已合并」的数），**保留 core 侧实测 wait_change**
  —— 这与判据 docstring 第 18 行写的原意一致（「把端到端伪造成已合并的数，core 那一遍却还在等 ⇒ 前后对不上」）；
- 判据里加一条**独立**的自洽性检查，让「core 还在等」这件事**能否定**那个假的端到端
  （例如：core 侧 wait_change > 30ms ⇒ 端到端**不许**被当成已合并）；
- 于是注入模式的正确结局是：**② 必须红**（假账不被接受）、**③ 必须绿**（假账**被抓出**），总退出码仍为 1；
- ③ **不许**是恒真：在「合并未实现」的状态下，注入也必须能被抓住（这条要能自证）。

### 返工② ★ **临时目录泄漏**：每次 `ctl_click` 在 %TEMP% 留一个目录，永不删

主控实测：`%TEMP%\agentctl_effect_*` **已积 70 个 / 2.0 MB**（每个含一张 PNG）。
根因：`core.py:2919-2925` 用 `tempfile.mkdtemp(prefix="agentctl_effect_")` 建目录，**全程没有删除**。

⇒ 这直接踩「**干完必须清场**」那条铁律（用户 2026-10-22 当面定的），而且是**产品级泄漏**
（每点一下留一个），不是测试垃圾。

**要求**：

- 帧读进内存后（或 `_act_after` 不用它时）**必须删目录**（`shutil.rmtree(..., ignore_errors=True)`），
  且要在 **`finally`** 里 —— 异常路径也不能留；
- 证据（要留的 PNG）**落仓内的证据目录**，**不许**把临时目录当证据目录；
- 判据里加一条断言：**动作跑完后 %TEMP% 里不得新增 `agentctl_effect_*`**（跑前跑后各数一次）。

### 返工③ ★ `os.environ` 的**进程级**改写 ⇒ 并发下会串

`core.py:2920-2926`：`os.environ["AGENTCTL_SNAP_DIR"] = _snapdir` —— 改的是**整个服务进程**的环境变量。
本机服务是**多线程**的（MCP/HTTP 并发处理请求）⇒ **并发的两次动作会互相覆盖对方的 SNAP_DIR**，
于是「帧与动作一一对应」这条刚砌好的防线在并发下会被打破 —— 而那正是 R1（观测帧被误当动作后帧）要防的。

**要求**：

- `_legacy(name, args, timeout=60)` **增加 `extra_env=None` 参数**，把额外 env **合并进该次子进程的 env**
  （`env={**_legacy_env(), **(extra_env or {})}`），**不许**改 `os.environ`；
- `_act()` 里改成 `rc, out, e = _legacy("act.py", argv, timeout=…, extra_env={"AGENTCTL_SNAP_DIR": _snapdir})`；
- 判据里加一条断言：**并发两次动作互不串帧**（或至少断言 `os.environ` 里**没有** `AGENTCTL_SNAP_DIR` 残留）。
