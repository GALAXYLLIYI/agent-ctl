## 一、目标（一句话）

修一个**语义缺陷**：act 在「等生效预算耗尽」时把「我没机会看到」和「我看到了、确实没变」混成同一个值 `False`
⇒ core 把它判成 **code=8「确认没变」** ⇒ **agent 不重试** ⇒ 自动化流程静默停住。

**本刀只改这一处判定，不改任何时间预算，不碰契约。**

## 二、改什么（只有一处逻辑，两个出口共用）

**落点**：`legacy_tools\_src\act.py` 的 `_wait_effect`（现 1345–1382 行）—— **两个「预算耗尽」出口**：

| 出口 | 位置 | 何时走到 |
|---|---|---|
| 出口① | `act.py:1353-1357` | 循环顶部、**采样之前**检查 deadline（实测最常走这条） |
| 出口② | `act.py:1377-1381` | 本轮采样+diff 之后检查 deadline |

**改后口径（两个出口完全一致）**：

```
预算耗尽时：
  最后一帧(last) 与基线(base_img) **不同**  ⇒ 判 None（没测出来）⇒ core 判 code=5 ⇒ agent 会重试
  最后一帧(last) 与基线(base_img) **相同**  ⇒ 判 False（确认没变）⇒ core 判 code=8（语义不变）
  last is None（从未采到帧）                ⇒ 判 False（保持改前行为，避免退化路径漂移）
```

★ **推荐实现**：加一个极小的模块级辅助函数（例如 `_budget_verdict(base_img, last)` → True/False/None 语义），
两个出口都调它 ⇒ **杜绝两处口径漂移**。**不得**改动其它任何分支。

★ **判 None 而不是判 True**：这样闪烁（变一帧又变回）永远不会被判成功（None ⇒ code=5 ⇒ 重试，不是成功）。
