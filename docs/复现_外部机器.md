# 外部机器复现指南（2026-10-25 · 工单 W4）

> 此前所有判据都只在作者机器上跑过。这份指南给陌生人：装环境 → 自检 → 跑无桌面判据 →（可选）桌面判据 → 回贴结果。

## 一、前置

| 项 | 要求 |
|---|---|
| 系统 | Windows 10/11 x64（32 位未测）；跑桌面判据需**本地交互登录** |
| Python | **3.12（硬要求）**，`python --version` 必须显示 3.12.x，别的版本没测过 |
| git | clone 用 |
| PowerShell 7 | `pwsh`，走 install.ps1 安装路径时用（直接跑判据用 cmd 也行） |

## 二、步骤

① clone（二选一）：

```text
git clone https://github.com/GALAXYLLIYI/computer-use-gate agent-ctl
git clone https://gitee.com/GALAXYLIYI/computer-use-gate agent-ctl        # 国内直连
```

② 环境自检（离线只读；唯一写动作是往 %LOCALAPPDATA% 放一个自删探针文件）：

```text
python -X utf8 tools\env_probe.py
```

退出码：**0=全满足；1=有硬阻塞（❌，先修再继续）；2=只有警告（⚠️，可继续，缺的一般只影响桌面判据）**。每条 ⚠️/❌ 都带「建议：」，照着做。装版可改走 `pwsh -File .\install.ps1`（README 口径）。

③ 装依赖：`python -X utf8 -m pip install -r requirements.txt`

④ 跑**无桌面判据**（不需要交互桌面；SSH/服务会话也能跑；cmd 下先 `set PYTHONPATH=src`，pwsh 下 `$env:PYTHONPATH="src"`）：

```text
python -X utf8 tests\_P3_M19_语义修复_判据.py        # 三态语义（假时钟）
python -X utf8 tests\_P3_看不清不计刹车_判据.py      # unobservable 不计连击
python -X utf8 tests\_写死路径判据.py                # 无绝对路径写死
python -X utf8 tests\_P3_审计导出_判据.py            # 审计导出（--inject 必红）
python -X utf8 tests\_P3_并发原语_判据.py            # 并发原语（--inject 必红）
python -X utf8 tests\_P3_环境自检_判据.py            # 本判据（--inject 必红）
```

全绿=rc 0。每条判据自带 `--inject`（注入坏实现必红），有疑虑就加跑：`--inject` 必须**红**，不红=判据自证。全量判据与判据的对应关系见 `docs\测试索引_判据对照.md`。

⑤ 桌面判据的前提（**不满足就别跑，跑了结果不可信**）：

- env_probe 的「交互桌面」✅（OpenInputDesktop 打得开）；「屏幕数」≥1；
- 会话里显示器**在点亮状态**（RDP 最小化/断开会把会话挂起，窗口消失/抓屏全黑）；
- 判据跑的时候**不要动键鼠**（判据要打真输入，人手一插就是变量）。

⑥ 结果怎么贴：贴 env_probe **完整输出**、每条判据**最后 3 行**（含【绿】/【红】行与退出码）。失败分三类：

- **A 环境问题**：env_probe 有 ❌/⚠️ 与之对应 → 先照建议修环境，修完重跑；
- **B 判据真红**：环境全 ✅、无桌面判据红了、且该判据 `--inject` 也正常红 → 带完整输出去开 issue（GitHub/Gitee 均可）；
- **C 判断不了**：原样全贴，**别删行、别摘录**，让维护者看全文。

## 三、必须写明的三件事

1. **哪些判据需要交互桌面**：快车道 w2/w3/wI/P0/默认关闭、`s2_/s3_/s5_` 验收、全部 `_P1_`/`_P2_` 动作面、`_T1_`、视口/语义屏/图标/帧复用/滚动按键——名字里有「帧/屏/点击/输入/弹窗/边框/滚动」的，默认按需要桌面对待；拿不准就先看该判据文件头的「跑法」。
2. **无头（服务会话/SSH/计划任务）会怎样**：`GetDesktopWindow` 仍能返回句柄、UIA 树可能为空、抓屏可能全黑或 0×0 ⇒ 判词大量 unknown、或把「没看见」误判成「确认没变」。**这些结果一律不可信**——是无头环境的物理限制，不是产品缺陷。
3. **失败不算产品缺陷的判断口径**（满足任一条，先怀疑环境）：env_probe 有 ❌；缺 pywin32/uiautomation/PIL 还硬跑桌面判据；无交互桌面/显示器熄屏/RDP 已断开时跑了桌面判据；DPI 缩放 >200% 的混合多屏（未测区）；杀软/组策略拦 SendInput 或拦写 %LOCALAPPDATA%。**环境项全 ✅ 且无桌面判据全绿、桌面判据仍红 ⇒ 这才算产品疑点**（走 ⑥-B）。
