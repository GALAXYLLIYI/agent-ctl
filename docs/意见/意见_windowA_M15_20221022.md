## Q1｜字框合并规则怎么定？

**结论：[确定] 一条规则就够：同行（垂直中心差 ≤ 0.5×min(h)）+ 紧邻（水平 gap ≤ 0.5×min(h)）+ 同号（h 差 ≤ 25%），按 x 排序贪心合并；标点并入左词，空格（gap>0.5×h）断词。**

理由：实测中文逐字框首尾相接（文 x=31,w=32 → 件 x=63，gap=0），半字宽阈值同时覆盖紧排与轻字距，不必按「字宽倍数」精确调参——用 **h 而不是 w** 做尺度基准是因为标点框 w 只有半字（w 会把阈值拉小误断）。字号一致性用 25% 容差而不是严格相等：OCR 对同一行不同字号（富文本）本就该拆词。中英混排：Windows.Media.Ocr 对拉丁文本一般已按整词给框，合并只作用于 CJK 框 [待核实：拿本机一段英文 UI 实测确认，一行代码的事]。词框输出 = 成员框并集 + conf=min(成员 conf)。

```
def merge_word_boxes(words):                      # words=[{x,y,w,h,conf,t}]
    out = []
    for b in sorted(words, key=lambda k: k["x"]):
        p = out[-1] if out else None
        if (p and abs((p["y"]+p["h"]/2) - (b["y"]+b["h"]/2)) <= 0.5*min(p["h"], b["h"])
              and b["x"] - (p["x"]+p["w"])        <= 0.5*min(p["h"], b["h"])
              and abs(p["h"] - b["h"])            <= 0.25*max(p["h"], b["h"])):
            p["x"],p["y"] = min(p["x"],b["x"]), min(p["y"],b["y"])
            p["w"] = max(p["x"]+p["w"], b["x"]+b["w"]) - p["x"]
            p["h"] = max(p["y"]+p["h"], b["y"]+b["h"]) - p["y"]
            p["conf"] = min(p["conf"], b["conf"]); p["t"] += b["t"]
        else:
            out.append(dict(b, h_pad=False))
    return out
```
判据：测试窗渲染已知词条（文件/保存全部/确定），合并后与 GT IoU≥0.8、召回 100%；实测样例「文+件」必须合成一框（gap=0，h 差 2/32=6%），跑红框架直接可用。

**结论：[确定] 不是——UIA BoundingRectangle 是「屏幕」物理像素，既非客户区相对也非逻辑；仓里自己就有明文。**
