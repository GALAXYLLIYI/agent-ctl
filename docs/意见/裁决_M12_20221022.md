## 五、失败口径（一字不许松，M12 阶段二的验收硬条件）

1. act 回传的 JSON **解析不到** ⇒ core **一律回落** `wait_change`（多等 300ms），
   **绝不许**把解析失败当 `changed=False`；
2. `degraded=true`（`is_blank`）⇒ **unknown** ⇒ 落 **code=5**，**永不当成功**；
3. `changed=False`（core 自己的尺子判的）⇒ 落 **code=8**（「画面没变化」），**不许**当成功；
4. 帧的 **mtime 必须晚于注入时刻**（core 记 `t_inject`）⇒ 不满足就**回落**
   （这是 MiniMax Code 提的 R1，最严重：观测帧被误当动作后帧 ⇒ 每次动作都落 code=8 ⇒ agent 永远收不到成功）；
5. `budget` **一秒不减**：`act.py:1082 POLL_BUDGET_MS=800` 与 `framecache.py:101 WAIT_BUDGET_MS=300` 都保留。
