## 1. 结果定义（必须逐项可检查）

```
① 一个只读体检脚本（路径二选一：tools\station_check.py 或 src\agentctl\station.py）
   输出 = 人读一页 + `--json` 一份，字段**必须**含：
     channels.uia.nodes(int) / channels.uia.usable(bool)
     channels.ocr.usable(bool)
     channels.cdp{port:int|None, usable:bool}
     runtime.act_py_md5(str,8位) / runtime.repo_act_md5(str,8位) / runtime.consistent(bool)
     desk.border_windows(int) / desk.notepad_leftover(int)
     env.disk_free_gb(float) / env.model_keys{minimax:bool,glm:bool,mimo:bool}   ← 只许布尔，不许任何密钥明文
     auth.pass_present(bool) / auth.pass_expires(str|None) / auth.lease_holder(str|None) / auth.brake(bool)
     verdict(str: ready|runtime_drift|no_pass|brake_on|blind|dirty_desktop)
     advice(str,≤60字)
② 一条判据 tests\_工作站体检_判据.py（真机、不 mock）：
     · 正常态 ⇒ rc=0，verdict ∈ {ready, dirty_desktop}，且 runtime.consistent=true
     · 负例 ⇒ 故意把 runtime 侧 md5 与 repo 侧 md5 比对改成"永不相等"（--inject）
               ⇒ verdict 必须是 runtime_drift、rc=1（判据变红）
     · 环境不满足（无证/无窗）⇒ rc=2 并打印"验不了"，**不许写绿**
③ 文档：agent-manual 框架新增一节，写清"六条体检项 + 三档判定"；本单回执按 §6 六行
④ 数据：判据跑的原始输出落 work\_station_check_<ts>.txt
```

## 2. 判定口径（三档）
| 档 | 条件 |
|---|---|
| **算解决** | ①字段齐全且 ②两条腿都跑过（正常绿 + --inject 红）+ ④输出落盘 + 文档 ③ 已写 |
| **不算解决** | 只写脚本没判据 / 判据没跑 --inject / 只打印不做 verdict / 写了 verdict 但 advice 空 |
| **算验不了** | 无通行证或无窗口 ⇒ rc=2，并在回报里明写"验不了 + 缺什么" |

## 3. 证据要求
```
· 正常跑输出路径 + --inject 跑输出路径（两份都要给）
· runtime 侧与 repo 侧 md5 各一行（前→后）
· 判据文件里 check 数 ≥ 6（字段齐全性 4 + 负例 1 + 三档 1）
```

## 4. 边界
```
· 只读：不许改任何产品代码/默认值；不许 spawn 键鼠动作
· 不许读或打印任何密钥明文（只判"配没配"）
· 发现别的问题 → 写进回报 §5「顺手发现」，不自行开工
· 草案一律落在各自的 work\_draft_<agent>\ 里，不许直接改 src\
```

## 5. 分工与模型预算
```

```

## 6. 回报格式（六行，固定）
```

② 没做成什么 + 为什么
③ 判据结果：绿 x / 红 y / 验不了 z（附两个输出文件路径）
④ 证据：md5 前→后 / 关键日志行
⑤ 顺手发现（不改，只报）
⑥ 需要拍板的（≤2 条）
```

## 7. 主控裁决（2026-10-19 18:40，DSH 答 Codex 草案两问）

```
① 不加第 7 档 cannot_verify —— verdict 枚举是契约，改它会让 MiMo 的判据对不上。
   替代做法：
     · 字段层加 runtime.blocked[] 与 runtime.verdict_status ∈ {ok, cannot_verify}
     · 「读不到」时 rc=2（验不了），**不许**报 runtime_drift
       ——把"没权限读"当成"代码漂移"会让别人去修不该修的代码，这是最贵的一种假红。
② --inject 语义定死：**注入 = 人造比对**。
   --inject 腿允许在"runtime 侧读不到"时用常量占位 md5，只为证明"比对逻辑本身会红"；
   真实漂移检测只发生在正常腿，读不到就如实报 cannot_verify，不许占位。
```
