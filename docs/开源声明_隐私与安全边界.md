## 二、隐私与数据边界

### 2.1 无遥测、不上传

- 本项目**没有任何遥测、统计、上报或回传逻辑**。
- 服务**只监听 `127.0.0.1`**（回环地址），不对外网开放。
- 本项目**不向任何第三方服务发送数据**。

### 2.2 数据落在哪里

| 数据 | 位置 | 说明 |
|---|---|---|
| 证据（时间线 jsonl、前后帧指纹、决策日志） | **`work\`** 目录 | ⚠ **含前后屏幕截图**，属敏感本地数据 |
| 授权状态、通行证、急停标志 | `%LOCALAPPDATA%\AgentCtl\`（可用 `AGENTCTL_HOME` 改） | 本机 |
| 会话令牌 | `%AGENTCTL_HOME%\state\token` | 本机 |

> ⛔ **`work\` 目录（含截图）不要提交到版本库。**
> `.gitignore` 已排除 `work\`、`baseline\`、`dist\`、`*.bak*`、`*.png`、`*.jpg`，
> 但**发布前仍应自己核一遍**（`python -X utf8 tools\presubmit_scan.py`）。

### 2.3 数据里有什么（会被读到日志里的东西）

- **窗口标题** —— 可能含文件名、账号名、客户名、订单号。
- **坐标与控件名** —— 可能暴露你在操作什么。
- **前后屏幕截图** —— 可能含你的聊天、邮件、账号、余额、内部系统。

> ⚠ **转发日志前先过一遍。** 本项目提供的是「可审计」，不是「可公开」。

### 2.4 分发包刻意不含什么

`tools\pack_dist.py` 的白名单**刻意排除**：

| 排除项 | 原因 |
|---|---|
| `baseline\` | 历史项目快照，**含真实手机号、对话记录、`_auth` 授权状态、明文 API Key** |
| `work\` | 运行日志与会话 token |
| `dist\` | 构建产物 |
| `__pycache__\`、`*.bak*` | 编译缓存与本地备份 |
| `case_data.json` | 含真实手机号 + 身份证，**在永久排除名单里** |

打包走三道闸门（**脚本，不是人肉检查**）：

| 闸门 | 位置 | 作用 |
|---|---|---|
| 抽取闸门 | `tools\make_legacy_dir.py` | 扫手机号 / 身份证 / 密钥赋值，命中即不复制 |
| 打包闸门 | `tools\pack_dist.py` | 白名单 + 敏感名 + 隐私复扫，缺控制链路即中止 |
| 核验闸门 | `tools\verify_dist.py` | **独立重新实现**一遍判据，只解包检查，不信打包脚本 |

> 核验脚本刻意**不复用**打包脚本的函数 —— 同一份代码既是运动员又是裁判，出错就一起错。

## 三、安全与授权边界

### 3.1 默认关闭

**装完、开机、重启之后，闸口默认是关着的。**

- 没有通行证时，A / B / C / D 四个档位**一律被拒** —— agent 连一次点击、一次截图都发不出去。
  `gate.check()` 逐档返回 False，`gate.require()` 直接抛 `GateDenied`
  （**不是警告、不是降级，是拒绝**）。
- 安装脚本与主程序里**没有**写通行证的代码 —— **装完不会替你签任何证**。
- 自验命令（不碰你的真通行证）：

  ```powershell
  python -X utf8 tests\_默认关闭_判据.py
  ```

### 3.2 五道闸

每个 UI 动作落到键鼠之前，依次过：

1. **人类签发** —— 弹窗一次给 ABCD，30 分钟 / 60 次；**弹窗不可被 agent 代点**；
   密钥明文不落盘、不回显（只存加盐 SHA-256）。
2. **租约** —— 任务→窗口，**只追加不覆盖，子随父亡**；同一时刻只允许一个 agent 动手。
3. **帧凭据** —— **旧帧点新画面 = 拒绝**；不许拿几分钟前那张图的坐标去点。
4. **敏感窗服务端终判** —— 用户的授权弹窗（标题 `本地 agent电脑控制授权`）任何动作一律禁止，**不问、不放行**；
   `--xy` 直点也拦。
5. **急停一票否决** —— 文件级，拉下即全灭；急停压过一切。

之后是**证据链**：前后差分 / `hit_test` 归属 / 决策日志。

### 3.3 急停三通道

任选其一，**互相独立**：

| 通道 | 说明 |
|---|---|
| 面板 ⏹ | 悬浮面板上的急停按钮 |
| `Ctrl+Alt+Home` | 全局热键 |
| 删急停标志 | 删掉急停标志文件 |

- 急停一拉下，所有自动控制**当场停**，并**联动吊销当前租约**（续期不再受理）。
- ⛔ **关面板 ≠ 解除急停。** 急停是安全状态，不会被随手关窗口带走。

### 3.4 明确的使用范围

✅ **本项目适合用来做**

- 在**你明确授权**的窗口上执行动作，并留下可复核的证据；
- 需要「事后能证明 AI 干了什么」的场景；
- 在自己的机器上、愿意接受「默认拒绝 + 逐次签发」这个节奏的实验。

⛔ **本项目不得用于**

- **绕过风控、验证码或权限边界**。本项目是「让**授权过**的动作留下证据」，
  **不是**「帮你通过它不该通过的检查」；用它去绕验证码/风控，既违反对方的使用条款，在法律上也很可能出问题。
- **无人值守批量操作** —— 每 60 次动作就要人点一次授权，这正是它的设计。
- **在生产机或有真实账号的机器上第一次就开闸** —— 请先在测试环境、测试账号上把整套流程走一遍。

### 3.5 能力边界（安全相关的那部分）

> 完整的能力边界见 README 的「能力边界与已知限制」。**与安全直接相关的两条**：

- **判词是三态**：`code=0` 生效 / `code=8`「确认没变」/ `code=5`「没测出来」。
  **`code=8` 和 `code=5` 都不是成功。** 「没测出来」曾被报成「确认没变」，现已统一走三态映射。
- **慢应用可能被判「确认没变」**：实测检测率矩阵（450ms 预算）下，
  响应 **300ms 及以上整段掉到 0%** 检出率 ⇒ 切线在 **200ms**，不在 450ms。
  **不要把「没变化」当失败重试到天荒地老，也不要当成功。**
