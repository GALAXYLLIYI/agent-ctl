# 怎么测这个组件（agent-ctl 验收手册 · 2026-10-24）

> 给**人**用的。目标：30 分钟内回答三个问题 ——
> ① 它**能不能跑**？ ② 它**做对了没有**（不是"命令没报错"）？ ③ 出问题**该看哪一条**？
>
> 所有命令都在**仓库根**跑，路径用相对路径；需要绝对路径的地方标 `<仓根>`。

---

## 〇、先记住三条判读纪律

1. **退出码分三档**：`0`=全绿 ｜ `1`=有红 ｜ `2`=无红但**有验不了/待通知**（**不是绿**）。
2. **"动作发出去了" ≠ "事情发生了"**：`code=8` 就是"发了但画面没变"，**不许当成功**；
   真正算成功的是 `code=0`（变化落在声明区域）或 `code=8` 且面板/回执明确写"确认没变"。
3. **改完代码必须重启 MCP server** 才生效（老进程持旧码）——`pythonw -m agentctl.mcp_http`。

## 一、10 分钟冒烟（不碰 GUI，任何人可跑）

```powershell
cd <仓根>

# 1) 全量验收（一条命令出总表）
python -X utf8 tools\验收_发版.py

# 2) 默认关闭（装完不签任何证 ⇒ 一切写动作被拒）
python -X utf8 tests\_默认关闭_判据.py

# 3) 动作面刹车（急停不许自解锁 + 阈值两级响应）
python -X utf8 tests\_P2_动作面刹车判据.py

# 4) 刚修的两条
python -X utf8 tests\_P3_M19_语义修复_判据.py          # 三态语义
python -X utf8 tests\_P3_M20_core加长观测_判据.py      # 慢应用救回（900ms）
python -X utf8 tests\_P3_W4_act安全批_判据.py          # _rdy / targets 空列表
python -X utf8 tests\_P3_ctl_quiz_verify口径_判据.py   # 多选校验口径（集合判等）
```

**期望**：全部 `exit 0`。
**注意**：`tools\验收_发版.py` 在**干净工作区**（暂存区为空）会把 presubmit 判成「验不了」⇒ `exit 2`。
想拿 `exit 0`：先 `git add` 一个真改动再跑（这也顺带证明 presubmit 扫了东西）。

### 判据要"有牙"（这一步别省）

挑上面任意一条，加注入参数跑第二次：

```powershell
python -X utf8 tests\_P3_M19_语义修复_判据.py --inject   # 期望 exit 1（红）
python -X utf8 tests\_P3_ctl_quiz_verify口径_判据.py --inject
```

**注入后仍全绿 = 判据是死的**（没在测东西），要当场记红。

## 二、通道与安全闸（10 分钟，需要签一次证）

```powershell
# 签一张 30 分钟的证（弹窗必须人点）
python -X utf8 legacy_tools\auth_popup.py --request "A,B,C" --minutes 30

# 只读通道：应该 200 且拿得到窗口清单
python -X utf8 tools\自检_mcp_http.py
```

**要专门验"拒绝是真的拒绝"**（这比验成功更重要）：

| 场景 | 期望 | 怎么造 |
|---|---|---|
| 没有通行证 | `code=10`（需先授权）或 `code=7`（需弹窗） | 等证过期后调一次 `ctl_click` |
| 急停拉下 | `code=11`，**且 agent 不许自己解** | 跑 `legacy_tools\brake.py stop`；再试 `ctl_brake action=release` ⇒ 必须 `code=9` 被拒 |
| 前台不对 | `code=5` | 目标窗口被别的窗口压住时点 |
| 坐标凭据过期/落点不归目标 | `code=12` | 拿旧 `capture_id` 点新画面 |
| 敏感窗（授权弹窗/UAC/任务管理器） | `code=3` | 对授权弹窗调 `ctl_click` |

> 急停只能**人**解：面板「▶ 解除急停」或 `python -X utf8 legacy_tools\brake.py release`。

## 三、真机效果（15 分钟，证明"慢应用能救回"）

自建靶场 + 独立 Edge profile（不碰你自己的浏览器）：

```powershell
python -X utf8 work\_M20_真机验收_20221023\M20_真机验收.py `
  --authdir "$env:LOCALAPPDATA\AgentCtl\_auth" --allow-non-temp-authdir `
  --ms 300 --cases fast,slow,never
```

| 档位 | 含义 | 期望码 |
|---|---|---|
| `fast` | 点了立即变 | `code=0` |
| `slow` | 点了 **300ms** 后才变（甲案救） | `code=0`（回执写「加长观测被触发」） |
| `never` | 点了永远不变 | `code=8`（"确认没变"，**不是成功**） |

边界（口径已钉死）：

- `--ms 900 --cases slow` ⇒ **仍是 `code=0`**（加长观测预算 900ms 覆盖 800~1300ms 段）；
- `--ms 900 --cases never` ⇒ **仍 `code=8`**（没变就是没变，没被"救"成成功）；
- 单次 `fast` 偶发 `code=12` = 落点被残留窗口遮挡 ⇒ 已做"置顶 + 一次重试"，连跑 20 次应是 **0 个 12**。

## 四、真实业务回路（以 ctl_quiz 为例，5 分钟）

```powershell
# 页面开着（CDP 9222）时：
ctl_quiz action=status                 # 看页面/进度
ctl_quiz action=verify answers=<答案表.json>
```

期望（300 题实测口径）：`不一致=0`、`未作答=0`、`顺序差异≈48~50`（多选显示序≠key 序，**正常**）、`判定=PASS`。

**故意造一个错**（把某道多选的答案删一个 key 再 verify）⇒ `不一致=1` 且点名那道题。
这一步是防"只看 PASS"：**PASS 要能解释成"逐题集合都对"，不是"工具没报错"**。

## 六、红了怎么办（按顺序查）

1. **先看是不是在途态**：暂存区有别人的改动？MCP 没重启？live 没刷新？
2. **单跑该判据**（绕过验收器），拿原始退出码与第一条失败断言；
3. **看失败性质**：
   - `code=3/5/7/10/11/12` = 环境/闸门拒绝（不是产品错；按提示补证/置前/重拍）；
   - `code=8` = 发了没生效（真问题，查落点/前台/慢应用）；
   - `code=9` = 越权（agent 想解急停/放行敏感窗）；
4. **注入自证**：把实现改坏，判据必须红；不红 ⇒ 判据失效，先修判据再修产品；
5. **留证据**：把 `--out <json>` / 截图 / 退出码落盘；没有原始输出的"绿"不算绿。

## 七、这套东西**测不到**的（别自欺）

- 真实第三方应用（微信/网页后台/自绘控件）的慢响应——靶场是自建页面，只能证明机制；
- Canvas/游戏/PDF 内嵌/未开无障碍的 Electron：UIA 看不见，只能截图兜底（等于"看不清"）；
- 安装包在**干净机器**上的首次安装（本机没有安装版，`install.ps1` 未做端到端试装）；
- "用户会不会照做"——文档只能证明步骤存在，证明不了人照着能成。
