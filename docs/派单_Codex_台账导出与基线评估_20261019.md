## 0. 一句话目标
> 把「已经发生过的桌面动作证据」变成**可复算的数据集**，并量出**现有规则判词的覆盖率与错判率**——
> 为一个可选增强件（判词分类器 + 置信度校准）提供**基线**。**本单不训练模型。**

## 1. 结果定义（逐项可检查，路径固定）

```
① work\ledger\actions.jsonl        每行一条动作记录，字段**必须**含：
   ts, source(act|gate|judge), app{exe,cls,title_hash}, window{hwnd,gen,screen_version},
   intent{action,args_digest}, landing{xy|eid,归属判定}, diff{changed,bbox,area_ratio},
   verdict{value,reason}, unknown(bool), evidence{before,after,crop,log_line_no}
   ★ 只脱敏：标题存 hash，不留窗口标题原文；不存任何密钥/剪贴板内容
② work\ledger\schema.md           字段定义 + 每条字段"从哪个源、怎么算出来的"
③ work\ledger\coverage.md         按**应用**分组的覆盖统计表：
   应用 | 动作数 | verdict 分布 | unknown 占比 | 判词可用率
④ work\ledger\baseline_rules.md   现有规则判词作为"基线策略"的评估：
   覆盖率 / 错判率（有真值子集时）/ 弃识率(unknown) / 分应用明细
⑤ work\ledger\eval_plan.md        评估方案：**按应用分组**划分训练/评估（不许随机划分），
   为什么这样分、真值怎么来、哪些样本必须剔除
⑥ work\ledger\BLOCKERS.md         夜间遇到"要人拍板"的事，逐条记（时间+问题+你选了什么临时方案）
⑦ work\ledger\RUNLOG.md           每 15 分钟追加一行：时间 + 已完成 + 下一步 + 是否卡住
```

## 2. 判定口径（三档）

| 档 | 条件 |
|---|---|
| **算解决** | ①~⑦ 全部落盘；`actions.jsonl` 能被一个**独立小脚本**重新解析并复算统计（统计数与你 §④ 一致）；`eval_plan.md` 明确写出"剔除 unknown、按应用分组"的理由 |
| **不算解决** | 只导数据不评估 / 随机划分 / 把 unknown 当负样本 / 统计数无法复算 / 把大文件内容贴进对话 |
| **算验不了** | 数据源缺失或读不到 ⇒ 明确写"验不了：缺 X"，**不许编数**，其余项继续做 |

## 8. 已知陷阱（前人踩过，别再踩）
```
1. **unknown ≠ 失败**：它是"验不了"，既不能当正样本也不能当负样本 ⇒ 单独一桶统计
2. **按应用分组**：随机划分会把同一应用背样本混进训练/评估，准确率高得离谱但线上必崩
3. 日志里有中文与括号嵌套，**别用宽正则一把抓**；先按行首时间戳切段，再逐段解析
4. 我们的判词来源不止一个（act.log / gate.log / 判据输出）⇒ 必须写 `source` 字段
5. 别把 work\_actions\ 里的 PNG 读成像素去重算一遍（那是另一单的活）；本单只做**记录级**导出
6. 时段里有几轮判据是我跑的（run_all_*.txt 共 69 份），可作为 judge 来源，但要标明批次
```
