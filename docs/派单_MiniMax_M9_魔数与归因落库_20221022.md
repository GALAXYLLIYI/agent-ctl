## 2. M4：SendInput 统一带专属 `dwExtraInfo` 魔数

```
① 魔数常量在 agentctl 内定义一处（建议 0xA6E17，或你选一个带前缀不易撞的值），
   所有 SendInput 路径统一带上，并写进 docs/AGENT接口.md
② 判据 tests/_P2_魔数_判据.py：
   - agent 产生的事件 dwExtraInfo == 魔数
   - 非 agent 注入的 dwExtraInfo != 魔数（--inject 造假事件覆盖，必须变红）
③ 独立核验：改前/改后 MD5 + 判据原始输出落盘
```

**改动面只限 `dwExtraInfo` 填充**；不许顺手动别的逻辑。

## 3. M5：归因层落库为 `src/agentctl/attribution.py`

```
① 按 M2 设计稿实现归因判定（注入位 + timeline 对账 + DPI 感知 + 降级语义）
② 对外暴露：**不碰 contract**
   - 走 legacy_tools 或独立 CLI，判据从命令行可调
   - 若将来要挂工具面，走 data.归因（**data 是自由字段，不受 A3 键集冻结约束**）
③ 判据 tests/_P3_归因落地_判据.py：四档各有可核证据；
   「未知」不得硬猜成「真人」；--inject 变红
④ 跨进程单调钟对齐：用 clock.Clock.session_open()（clock.py:90）落地并验
```

### 3.1 三方意见里已经定死的两条口径（照做，别自创）

1. **归因走 `data.归因`，不要复用 `blind_spots`**（DSH）：
   `blind_spots` 语义是「盲区（我没看见）」，归因是「谁干的」——
   **混了以后就分不清「我没看见」和「不是 agent 干的」**。
2. **contract 方向是瘦身不是加码**（ZCode）：`tools/list` 已 30,630 字
   （desc 9,673 + schema 20,957），A1 余量 149 字、A3 键集冻结 ⇒
   **本单一律不碰 contract**；将来若要进，必须与「desc 外移 docs」并单置换。

  交付文档里「未验的路径」必须显式写出来，不许写绿。

## 5. 判定口径

| 档 | 定义 |
|---|---|
| **算解决** | 魔数判据先红后绿有记录；归因四档各有证据；`--inject` 变红；MD5 前后齐全；字节级 diff 落盘 |
