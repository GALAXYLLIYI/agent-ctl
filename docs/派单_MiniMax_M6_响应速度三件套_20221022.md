## 2. 三件事（每件都要：改动面 + 判据 + 实测数字 + 边界）

### ① D4/D2 帧复用 + 只 diff 变化区（**零新依赖，最该先做**）

- 现状：`screen_version` + TTL 已经签发，但**调用方基本不复用**；每步都重扫
- 要做：调用方能凭 `capture_id`/`screen_version` 复用帧；只有版本进位才重扫；
  且**只对变化区**重扫/重 OCR
- 关键：**别用「整屏 hash」当变化判据**（实测 90.6% 恒变）；用区域级 + 指纹（6.45ms/次）
- 判据：`tests\_P2_帧复用_判据.py` —— 同一 `capture_id` 复用时**不得触发二次 UIA 扫描**
  （可数调用/计时），版本进位后必须重扫；--inject 变红

### ② D2 GPU 抓帧（对标 `创新思路` §二-2）

- 要做：Windows.Graphics.Capture（WGC，GPU 路径）或 DwmRegisterThumbnail（DWM 缩略图，**取缓存不触发重绘**）
  替代 PrintWindow/mss 抓帧
- 已知：本机已内置 `vendor\winrt`、`vendor\windows_capture` ⇒ **优先用已内置的，别引新依赖**
- 风险：DRM/受保护内容黑屏；WinRT 绑定
- 判据：`tests\_P2_GPU抓帧_判据.py` —— 新旧两路取同一窗口内容**像素一致**（或明确差异并说明原因）＋ 耗时对比数字落盘

### ③ D1 图标字体模板匹配（**治「纯图标没文字只能估坐标」**）

- 要做：Segoe Fluent Icons / Segoe MDL2 Assets **码点公开** ⇒ 渲染成 bitmap 集，
  对候选区域做归一化互相关（NCC）匹配；**不用任何模型、不用 GPU**
- 输出：图标 ⇒ 码点 ⇒ 语义名（如 `` 之类 ⇒ "设置"），作为**多一条证据**，不替代 UIA/OCR
- 判据：`tests\_P2_图标匹配_判据.py` —— 对本机真实界面（计算器按钮、资源管理器、记事本菜单）里的已知图标匹配成功；
  --inject 变红
- 依据：`https://learn.microsoft.com/en-nz/windows/apps/design/iconography/segoe-fluent-icons-font`
