## 一、改了什么（只有一处逻辑，两个出口共用）

落点：`legacy_tools\_src\act.py` 的 `_wait_effect`（现 1359–1417 行）——**两个「预算耗尽」出口**
（改前 1353–1357 / 1377–1381，现 1389–1392 / 1414–1417）。

**改前**（两个出口逐字相同）：

```python
        if _t.perf_counter() >= deadline:
            return {"生效": False, "轮次": rounds, ...}
```

**改后**：

```python
        if _t.perf_counter() >= deadline:
            return {"生效": _budget_verdict(last_d), "轮次": rounds, ...}
```

**新增模块级辅助函数**（派单 §二 推荐的写法 ⇒ 两处口径不可能漂移）：

```python
def _budget_verdict(last_d):
    if not last_d:
        return False            # 从未采到帧 ⇒ 保持改前行为
    if last_d.get("changed") is True:
        return None             # 最后一帧与基线不同 ⇒ 没测出来（code=5 ⇒ agent 会重试）
    return False                # 其余 ⇒ 确认没变（code=8，语义不变）
```

配套两处小改（**零逻辑漂移**，只为了让出口能吃到判差）：

- `last_d = None`（循环前初始化）；循环里 `d = _img_diff(base_img, cur)` 之后立刻 `last_d = d`。
- 两个出口只吃 `last_d`，**不再重算 `_img_diff`**（见 §三）。

### ★ 主控复核补充已落地：不再二次判差

主控实测 `_img_diff` 在 1632×1191 全尺寸帧上 **13.84ms/次**（20 次平均）。
第一版实现（出口里再算一次 `_img_diff(base_img, last)`）会让预算耗尽路径**每次动作白加 ~13.8ms**，
总耗时变 450+13.8=**463.8ms**，破坏 act.py 自己写的「总耗时 ≤ 预算（永远不慢于改前的固定 sleep）」不变式。

改法（语义完全不变，只是不再算第二次）：循环里已经算过 `d = _img_diff(base_img, cur)`，
此刻 `last is cur` ⇒ `d` 正是 `last` 的判差 ⇒ **直接复用**。

**实测确认（§四 表最后一列）**：改前与改后的 `_img_diff` **调用次数逐场景完全相同**（6/6/6/2），
轮次相同（6/6/6/2），耗时相同（467.2/467.2/467.2/122.4ms，假时钟口径）⇒ **零额外开销**。

### 6.2 文案分支 —— **文案会变**（点名）

改后 `changed` 由 False 变 None 的那一格，文案随之变化：

| `生效` | 非演练文案 | 演练(dry)文案 |
