### 2026-10-22 12:58 主控清理 · **185 个记事本窗口**（用户当面提的）

用户原话：「你派任务要提醒开的记事本用完就关。现在几十个记事本我怎么帮你们关？」

**实况**：Windows 11 的记事本是**单进程多窗口**（pid 41492 从 7:48 一直活着），
判据/测量器**每跑一次开一个、从不关** ⇒ 一天堆到 **185 个可见窗口**：
112 个带 `*`（内容是判据敲的 `MM` / `m` / 粘贴垃圾）、73 个空的、1 个卡在
「是否打开来自不受信任来源的文件?」的 README.md 弹框。

**怎么清的（不杀宿主的 Notepad 进程）**：
1. 空窗口（无 `*`）⇒ 直接 `WM_CLOSE`，无弹框；
2. 带 `*` 的 ⇒ 先对子窗口 `RichEditD2DPT` 发 `WM_SETTEXT ""`（清空文档 ⇒ 标题变成「无标题」、`*` 消失）
   ⇒ 再 `WM_CLOSE` ⇒ **不弹保存框**、不丢任何有价值内容（内容全是判据垃圾）；
3. 那个信任弹框是 **Notepad 窗口内的 XAML 对话框**（不是独立顶层窗口）⇒
   按 **PNG 真实尺寸 2561×1529** 换算坐标点「取消」（⚠ 截图渲染宽 2000，比例 1.2805，坐标要换算）；
4. 最后剩的那个空窗口同样清掉。

**结果：185 → 0。** 宿主的 Notepad **进程没动**（pid 41492 保留，只是不再有窗口）。

**根因已派修**（docs\派单_MiniMax_M16_加速第二刀_20221022.md 红线第 9 条）：
判据/测量器开出来的记事本必须在 **finally** 里关掉；异常路径也要清；
判据加断言「跑前 N 个可见 Notepad 窗口 ⇒ 跑后仍 N 个」；⛔ 不许 kill 宿主的 Notepad 进程。
