## ① 基础通路

| 项 | 结果 |

## ② `ctl_find` → `ctl_fill(eid)` → 读回

```
ctl_find  name=文本编辑器  → eid=e2, capture_id=…
ctl_fill  hwnd + eid + text="accept fill eid" + from_capture
          → ok=True  code=0
UIA 读回  "accept fill eid"（逐字一致）→ PASS
```

> ★ 踩到一个**测试方法**的坑（不是产品缺陷）：记事本未保存前**磁盘文件是空的**，
> 直接读磁盘会得空串 → 误判失败。正确读回走 UIA ValuePattern。已把脚本改成走 UIA。

- core 并发接线（LockedDict + dispatch 串行开关）**桌面端无回归**；
- T3 在记事本上**构造不出“目标消失”**，有效样本必须换可关窗目标（已用 WinForms 补上）；
