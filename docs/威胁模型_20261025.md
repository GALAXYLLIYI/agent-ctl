## 一、资产（被保护的东西）

| 资产 | 存放 | 丢了会怎样 |
|---|---|---|
| 通行证 | `%LOCALAPPDATA%\AgentCtl\_auth\pass.json` | 伪造=任意动作可不经人 |
| 租约 | `_auth\lease.db` | 伪造=多写者并发，证据串不起来 |
| 急停旗子 | `_auth\_急停.flag` | 被删=急停失效 |
| 证据 | `work\_actions\*` | 被改=事后无法复算 |
| 面板/授权窗 | 独立进程 | 被代点=授权被绕过 |

## 二、攻击者模型

| 代号 | 假设 | 是否在范围内 |
|---|---|---|
| **A** 无本地权限的远程输入 | 只能通过 MCP/HTTP/键盘宏发指令 | ✅ 范围内 |
| **B** 有同用户态权限的 agent 进程 | 可读文件、可 SendInput、可 UIA Invoke | ✅ 范围内（**最重要**） |
| **C** 同用户恶意程序 | 可改文件、注入进程 | ⚠️ 部分（只保证“改证据可被发现”，不保证拦） |
| **D** 管理员/内核/物理访问 | 可关服务、改 ACL | ❌ 明确不覆盖（写入本文件即免责） |

## 五、结论（诚实版）

1. **已证明能拦的**：旧帧、敏感窗直点、正常输入误拉闸、面板代点（用我们的工具）。
2. **未证明**：原生 SendInput / UIA Invoke 代点、票据伪造、证据篡改、TOCTOU。**这些在写清之前，不许对外说“绕不过”。**
3. 下一步优先级：**T01/T02/T03/T06**（伪造与代点）→ 再 T05/T07 → T08。
4. 对平台（Windows Agentic OS）的定位：我们补的是**逐动作接地校验+三态判词+证据**，不是身份/隔离；两者正交，应做“provider”而不是“替代品”。

### 6.2 needs_desktop 语义（防误读）

`True` ⟺ 已有判据、预期明确、real 复验必须向真实桌面发输入 ⟺ 在 real 白名单（T09/T10/T11）。
T02/T03 方法虽涉及桌面输入，但预期未定、无判据 ⇒ 纸面项标 `False`、拒绝 real；补了判据才许改 `True` 并入白名单。
判据断言两边集合相等：`set(needs_desktop=True) == set(REAL_ALLOWED)`，改一边不改另一边必红
（`--inject` 从白名单删掉 T10 必红，证明判据有牙）。

### 6.3 退出码与零副作用承诺

- 退出码：`0` 正常｜`1` 参数错（含带开关闯非白名单项）｜`2` 需人工确认（real 未带 `--i-understand`）｜`3` 环境不满足。
- dry-run 零副作用：不 import pyautogui、不调 SendInput、不截图、不写仓内文件；交互桌面检查只在 real 链路。
- `_send_input()` 是唯一输入咽喉：v0.2 没有任何调用点；判据 monkeypatch 盯它 ⇒ dry-run 路径结构性到不了输入。
- 跑法：`python -X utf8 tools\threat_probe.py list ｜ dry-run Txx ｜ real Txx [--i-understand]`；
  判据正跑 `python -X utf8 tests\_P3_威胁模型_判据.py`，注入自证加 `--inject`（必红）。
