# 审计导出（2026-10-25 · 派单 Z2）

模块：`src/agentctl/audit.py`。纯函数、只用标准库、**不 import** core/gate/action_guard（词表内置并注明出处）；除显式 `write_report` 外不写盘、不跑动作、不联网。判据：`tests\_P3_审计导出_判据.py`（--inject 必红）。

## 接口
- `collect(events_path=None, evidence_root=None) -> dict`：读事件 JSONL（缺省 `%LOCALAPPDATA%\AgentCtl\state\events.jsonl`，不存在 ⇒ 事件按空处理并记 notes）与证据目录（缺省 `<仓>\work\_actions\*`，读每个子目录的 `evidence.json`）。返回 `{"events","evidence","notes","sources"}`；坏行/坏回执不丢，以带 `_error` 的占位记录保留。
- `summarize(records) -> dict`：三态/四类分布、按窗口/工具计数、时间范围、无法复算项清单。
- `render_markdown(summary, records, limit=50) -> str`：中文报告，含「无法复算项」；空数据写「无记录」。
- `write_report(path, text) -> str`：唯一落盘口（显式调用才写，UTF-8/LF，不静默建目录）。

## 口径
- **判词三态** = met（生效）/ no_effect（确认没变）/ unknown（没测出来），即产品口径 code=0/8/5。折算表：satisfied、accepted→met；no_effect_in_region、unsatisfied→no_effect；snapshots-incomparable→unknown。**折不进三态的原词不谎报**：changed_outside_target（世界自己动了）、denied（被拒）等按原词单列「三态之外」。
- **failure_class 四类** = rejected_env / unobservable / no_effect / action_failed，与 `core.failure_class` 同表（5→unobservable；8→no_effect；3/4/7/9/10/11/12/13→rejected_env；其余含取不到→action_failed，宁严）。成功不计；证据回执无 ok/code 口径 ⇒ 计「不适用」。
- 窗口：`window` → 事件 `payload.win.exe` → `hwnd`（记 `hwnd:N`）→「未知窗口」；工具：`tool` 字段，证据回执取 `action`。Top-N 在 summarize 存全量、render 按 limit 截行。
- 时间：`ts` / `t_wall`，ISO（含 +0800 无冒号）或秒/毫秒 epoch；统一折本地墙钟比大小，输出保留**原样字符串**；解析不了的进「结构存疑」。

## 无法复算项（报告固定小节）
- **像素层**：凡像素 diff 产出的判词（证据回执全部、事件流 causal）离线不能独立重算，需按 recompute_spec 用同一函数重算（阈值/分块/滤除不在本模块）。
- **结构存疑**：解析失败行、词表外判词、时间戳坏 —— 连结构层对账都缺输入。
- **运行时状态**：denied 等依赖租约/前台/目标窗现场的判词，只计数、不重判。哈希链（prev_hash/hash）本模块**不复核**（store.py 的职责）。

## 已知盲区
- 缺省事件路径在本部署不存在（真实事件流在 `work\timeline\timeline-*.jsonl` / timeline.db）；要审计真实流，把 `events_path` 指到 timeline JSONL 即可（行结构兼容：tool/t_wall/payload.verdict/payload.win.exe）。
- 证据回执没有 failure_class 字段 ⇒ 四类分布只覆盖事件流，证据只进三态与像素层清单。
- 「窗口」多为 exe/hwnd，无标题明文（时间线只有 `title_hash`），本模块不反查。
