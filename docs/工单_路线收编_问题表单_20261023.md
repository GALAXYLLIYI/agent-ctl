## §7 S2 落地工单（派 MiniCode · 2026-10-23）

### 7.0 结论先行

本单 = **原 S2**（AUTHDIR 收编为单一解析）+ **原 S1 的判据部分**（修复经复核撤销——洞已不存在；判据保留为回归闸）。派单依据：S2 是 §6 复核后**唯一仍成立的高危项**（A2 实锤，且实际覆盖面比原文认定的更差：env 覆盖只覆盖三方中的 1/3）。

### 7.1 目标（一句话）

签发方（auth_popup）与两侧闸门（老线 gate、新线 agentctl.gate）对"账本在哪"必须给出**同一个答案**，且该答案可被 `AGENTCTL_AUTHDIR` 在不动代码的情况下整体搬移。

### 7.2 契约（单一真相源）

1. 新建 `agentctl/authdir.py`（或并入既有共享模块，改动计划里定），唯一函数 `resolve() -> str`，规则两条、顺序固定：
   - `AGENTCTL_AUTHDIR` 非空 ⇒ 用它（绝对化；目录不存在时**写入侧**惰性创建，**读取侧**不创建只如实返回）；
   - 否则默认 `%LOCALAPPDATA%\AgentCtl\_auth`——与 T10 已统一的 `BRAKE_FLAG` 同一个 `_APP_DIR`，账本与急停同家。
2. 三个调用方全部改走它：老线 gate.py（现 `env or HERE/_auth`）、新线 gate 的 `_resolve_home()`（现四层）、auth_popup.py（现写死 `BASE/_auth`；**两份拷贝同改**）。
3. 老线侧若暂不能 import agentctl（S3 未做），允许 gen_legacy 生成时**内联同规则代码**——但不许手抄一份了事：必须纳入 gen_legacy 的生成 + 对账范围（沿用 P8 的机器盯防），`_md5台账.md` 出现对应条目。
4. 迁移：**不迁移**历史 `_auth` 目录内容（沿用原 S2 口径）。切换后首次签发落在新默认位置，旧证自然过期（通行证 ≤30 分钟寿命）；旧目录原样留盘不动。
5. 可见性：三方每次解析结果必须可从日志/输出一眼看出"本次账本在哪"（老线 D3 修复已带路径打印，其余两方补齐）。

### 7.3 不改什么

- 通行证 JSON schema、档位常量、错误码、计数语义（全属 S3）；
- 不合并两份 gate 逻辑（S3 的事）；
- 不动用户正在用的 `_auth`：**所有测试一律 `AGENTCTL_AUTHDIR=%TEMP%\…` 沙箱**（§5 规则 3）；
- 不重启在跑的 `agentctl.mcp` / `mcp_http` / `brake_daemon` / `守护_mcp_http`。**本单落地 ≠ live 已修**：live 生效需重启哪些进程、何时重启，由用户拍板（衔接 P4），交付物里必须写明生效条件。

### 7.4 验收判据（全部可执行；J1–J3 登记进 run_all.CRITERIA 并同步"判据条数"文档 59 → +3）
