## §2 建议动作（按依赖排序，附验收判据）

| 序 | 动作 | 范围 | 不改什么 | 验收判据（可执行） | 依赖 |
|---|---|---|---|---|---|
| **S1** | **补 fail-closed 守卫**：`require()` 读通行证返回空即抛 `GateDenied`，不得写回 | 老线 `gate.py` + 新线 `gate.py` 两处 | 不动通行证格式、不动计数语义 | 故障注入下 `auth_pass.json` **不得**被写成残缺 JSON（对照 #1047 T4 台架复现，修前必红、修后必绿）；正常路径零回归 | 无（最先做） |
| **S2** | **AUTHDIR 收成一个解析函数**：新建单一定义（如 `agentctl.authdir.resolve()`），老线 gate、新线 gate、`auth_popup` **三方都调它**；`AGENTCTL_AUTHDIR` 保留为覆盖项 | 三处调用点 + 一个模块 | 不迁移历史 `_auth` 目录内容 | 判据：设 `AGENTCTL_AUTHDIR=%TEMP%\x` 后，**签发写入位置 == 两侧闸门读取位置**（三方打印同一绝对路径）；不设时默认路径不变；删掉新线“已知分歧（未修）”注释 | S0（若选“只源跑”可简化） |
| **S3** | **gate 收编为单实现**：优先“老线 import 共享包”（`from agentctl.gate import …`），生成退为打包步骤；退路才是“生成 + 语义对账判据” | 老线 `gate.py` 的常量/档位/路径解析部分 | 不改对外错误码与契约 | 判据 A：两份 gate 的档位常量表、错误码表、路径解析结果**逐项相等**（不是逐字节）；判据 B：`legacy_tools` 直跑仍能过现有 `T7 37/37` | S2；B0 拍板 |
| **S4** | **加两条对照判据**：①`_双gate语义对照_判据.py`；②`_live同步_判据.py`（仓内 HEAD vs live 运行目录内容） | `tests\` + `run_all.CRITERIA` 登记 | 不动既有判据 | 两条都带**注入必红**对照（故意改一个常量，判据必须报警）；登记后文档“判据条数”同步 | S3（判据①依赖 S3 收敛后） |
| **S5** | **daemon 化（仅作演进，不进本轮）**：通行证状态迁入守护进程，对外本地 RPC | 新模块 | 不动文件格式（过渡期双读） | 前置：**稳态**争用实测（不是台架）；且必须给出“守护未起时的行为”设计（fail-closed 还是降级），并证明不会新增第二个 daemon 副本 | S1–S4 全绿；用户单独批准 |

**关于 S5 的反对意见（请 ZCode 一并评）**：现在闸门“没有守护也能 fail-closed”；迁入 daemon 后“守护没起 = 全拒”。急停 daemon 的历史（事件 #1504 两份 daemon、文档入口那份不弹窗）说明**守护本身也是重复源**。S5 若只拿 48% 这个台架数当理由，证据不足。

## §3 口径更正（三段文字里必须改的三处，防止错误扩散）

1. 删“三处 act.py 拷贝依赖 md5 台账**人工**核对全等”——台账是自动生成 + 自动对账（见 P8）。
2. “48%”必须带限定：**压力台架 / 故障注入 / 可达性参考**，不得写成“稳态读失败率”。
3. “回归测试成套”不是从零收拢——已有四十余条判据、`bench.py`、元判据、台账对账；⑤ 应改成“补两类对照判据”（P5 / S4）。
4. “重写不能解决”改为“重写**不划算**”：单模块重写确实能消掉拷贝，代价是重踩一遍已修的雷并丢掉疤痕注释。

## §5 给 MiniCode 的落实规则

1. **一次只做一单**；每单先交“改动计划”，经 DSH/ZCode 放行后再动手（沿用 S4/S5 的既有做法）。
2. **禁止**：手工改 `legacy_tools\_md5台账.md`；新增第二份逻辑拷贝；把 48% 当稳态写进任何文档。
3. **动 live 前隔离**：一律用 `AGENTCTL_AUTHDIR=%TEMP%\…` 跑判据，不许碰用户正在用的 `_auth`；不许擅自重启用户在跑的 `agentctl.mcp` / `mcp_http` / `brake_daemon`。
4. **每条改动必须配判据**，且判据要带**注入必红**对照（改坏必须报警）；只改代码不配判据视为未完成。
5. **留证**：改动前后 md5、判据输出、回归 `T7/T12/T13/T15` 结果；不能验的项必须显式写“验不了 + 原因”，不许沉默。
6. **交付即报**：说清“哪部分是照单做、哪部分是我判断加的”。
