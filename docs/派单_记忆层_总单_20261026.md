## 一、目标（v0 一句话）

给 agentctl 长出「episode 记忆库」：把 timeline.db 的动作事件流提炼成**观测+动作+三值结局**的
episode，落 sqlite + 向量，支持巩固（粗细两级 + 双阈值滞回）、检索（粗下钻 + 混合排序）、
经验提炼（workflow 入库 + last_verified 降权依据）。**纯本地、无守护进程、拉取式**（§6.6 第一刀纪律）。

## 六、巩固口径（minicode；阈值/常量只认 contract.py）

- `promote()`：未入段的 episodes（id > meta['promoted_until']）按 t 序成段；段边界条件（任一）：
  ① 与前条时间差 > `SEG_GAP_SEC`；② 距上个强制锚点 ≥ `ANCHOR_N` 条（锚点=强制段边界）；
  ③ 与段内已累积摘要的相似度 < `SPLIT_SIM`（话题切分）。
  段 summary = 段内 episode.text 顺序拼接，超 `SUMMARY_MAX_CHARS` 截断；写 segments 后推进 meta['promoted_until']。
- `merge()`：自 level 0 向上，相邻**存活**段（merged_into IS NULL，按 first_ep 相邻）两两算摘要相似度：
  > `MERGE_SIM` 且 **合并后 n_ep ≤ ANCHOR_N**（保锚点不被稀释）⇒ 建 level+1 父段（summary=子摘要拼接截断），
  子段 merged_into=父id。一轮只做一层，层间迭代直到无合并。
- `compact() = promote() + merge()`，**幂等**：重复调用不产生重复段/重复合并（以 meta 与 merged_into 判）。

## 七、检索口径（minicode）

`Retriever(store).query(text, k=5) -> dict`：
- 粗：全部**存活**段按 level 从高到低算摘要余弦，取前 3 段 ⇒ 其 episode id 区间为候选集；
  候选不足 k ⇒ 放开为全库。
- 细：score = `0.7 * cos(query_vec, ep_vec) + 0.3 * keyword_fraction`，降序取 k。
- 返回 `{"query": ..., "hits": [{"source": "episode"|"segment-summary", "score": ..., 行字段..., "segment_id": ...}], "workflows": [...]}`。
  segment-summary 命中也要返回（带出处原则：模型必须能区分「我记得」和「我记得个大概」）。
- workflows 匹配：查询词与 workflow.name/signature 的关键词命中，最多 3 条。

## 八、提炼口径（minicode）

`distill_workflows(store, min_success_ratio=0.8, min_actions=3) -> dict`：
- 按 session_id 聚 episode；动作数 ≥ min_actions 且 success 占比 ≥ 阈值的会话才提炼。
- target_sig：normalize 后把数字/坐标/eid 归一为 `#`（`re.sub(r'\d+', '#', …)`）。
- signature = `'→'.join(f"{kind}:{target_sig}")`；workflows 表 upsert（n_seen+1、success_ratio 滚动、
  last_verified 取 max(t)、example_session）。
- 返回 `{"sessions_seen":…, "workflows_upserted":…, "stale": [最后验证超 7 天的 signature]}`（§5.3 降权依据）。
