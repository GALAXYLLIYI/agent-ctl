## 任务

新建 `tools\agent_loop.py`（唯一文件）——**桌面闭环 demo agent**：

```
每步循环：
  1. 感知：ctl_screen(hwnd) 取结构化快照（或 ctl_shot 截图 + 视觉兜底）
  2. 决策：从快照选下一个动作（v0 用规则：找窗口→focus→打字→核验；不接 LLM——LLM 决策是 DSH 难点①，留接口 `decide(snapshot) -> action`）
  3. 动作：ctl_click / ctl_type（走 MCP HTTP 8761，带凭据 from_capture/expect_uid）
  4. 核验：动作回执的 code 三值（0/5/8）直接当 verdict
  5. 记忆：构造 Episode（contract.Episode，三值 outcome）→ add_episode；每 N 步 compact()
循环体 ≥3 步演示：打开记事本→打字"循环测试"→核验→记忆入库→retrieve 查回自己刚做的事
```

## 硬约束

- MCP 调用走 HTTP POST `http://127.0.0.1:8761/mcp`（stdio 不可用），工具名/参数看 `contract\tools.json`
- Episode 必须用 `agentctl.memory.contract.Episode`（不许自造字典）；outcome 用 verdict_from_code
- **发图前敏感窗拒绝**：若走视觉兜底，先用 `agentctl.memory.harvest._win_sensitive(exe, cls)` 判，命中⇒不发图（这是用户隐私铁律）

- 不接 LLM（留 decide() 接口）；不碰 core.py / contract / 既有判据；不做 git；LF/UTF-8
