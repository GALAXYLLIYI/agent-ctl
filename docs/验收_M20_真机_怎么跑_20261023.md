## 二、跑验收：**一条命令**

```powershell
cd <仓库根>
$env:AGENTCTL_AUTHDIR = "$env:TEMP\agentctl_m20_accept\_auth"     # 与签发时同一个 env
python -X utf8 work\_M20_真机验收_20221023\M20_真机验收.py --ms 300 --cases fast,slow,never
```

- 它会：开一个**独立 profile 的 Edge**（`--user-data-dir=%TEMP%\agentctl_m20_profile_*`，不碰你自己的 Edge）→ 打开靶场 → 在抓帧里找准四个按钮的**屏幕物理坐标**（按纯色定位块找，不靠算 ⇒ DPI/边框/标题栏都不会让落点偏）→ 每档先点「重置」复位基线 → 再点目标按钮 → 记**判词 / 码 / 耗时** → 出人话表 + JSON → 关浏览器、删临时 profile。

- **退出码**：`0` 全部符合 ｜ `1` 有档位不符合 ｜ `2` 用法错 ｜ `3` **缺有效通行证，未跑** ｜ `4` 环境问题（浏览器没起来/抓不到帧/落点没对准 ⇒ **未核到**）。

## 三、期望看到什么

### 3.1 三档的期望

| 档位 | 页面上的动作 | **期望** | 说明 |
|---|---|---|---|
| ① `fast` | 立即变（0ms） | **code=0**（变了） | 快路径：末帧≠基线 ⇒ 甲案**不触发** ⇒ 回执里**没有**「加长观测」字段 ⇒ 零额外等待 |
| ② `slow` | 延迟 `ms` 后变（默认 300ms） | **code=0**（**不再是 code=8**） | 这一档若出现「加长观测 做了=是」⇒ 甲案那条路**真的被走到**了（core 多看了一眼并改判） |
| ③ `never` | 点了什么都不变 | **code=8**（确认没变） | 「确认没变」语义**一点没丢**；这一档通常会看到「加长观测 做了=是、结果=None」⇒ core 确实多看了一眼、确实没变 ⇒ 原判不动 |

### 3.2 人话表长这样（**形状**，数字以你那次为准）

```
档位      期望                       实得码  耗时ms   加长观测       命中确认            结论
fast      code=0（立即变）           0       1234.5   未触发        靶场|fast|ms=300    符合
slow      code=0（不再 code=8）       0       1512.8   做了=是/281ms 靶场|slow|ms=300    符合
never     code=8（确认没变）         8       1420.3   做了=是/330ms 靶场|never|ms=300   符合
```

- 「**命中确认**」= 窗口标题里的按钮标记 ⇒ 证明**点中的是哪个按钮**（标题栏在客户区之外 ⇒ 不污染画面判词）。
- 「**加长观测**」= core 回执里的 `data.加长观测`：`做了 / 耗时ms / 轮次 / 结果 / 原因`。
  · `做了=是` ⇒ 甲案**触发**了（末帧==基线 ⇒ core 多看一眼）；
  · `做了=否`（字段整个没有）⇒ 末帧≠基线或没测出来 ⇒ 甲案**没触发**（**成功路零额外等待**，这是设计）。

### 3.3 结果怎么算「通过」

- `fast` = 0、`never` = 8、**`slow` ≠ 8**（应当是 0）⇒ 三档都对 ⇒ 退出码 0。
- `slow` = 8 ⇒ **不符合**：慢应用**没被救回**。先看 §四 排障（多半是落点没打中/页面没响应），再考虑「甲案没生效」。
- `slow` = 0 **且**「加长观测 做了=是」⇒ **甲案在真机上生效的直接证据**（core 自己多看了一眼并改判）。
- `slow` = 0 **且**「加长观测」字段**没有** ⇒ 变化是 **act 侧 800ms 预算内**就被抓到的 ⇒ 这一次**没有考验到**甲案；请把延迟往上扫（`--ms 600`，或跑 `slow2` 900ms）再看。

## 四、失败怎么判（照着查）

| 现象 | 多半是什么 | 怎么办 |
|---|---|---|
| 退出码 **3** + 「缺有效通行证，未跑」 | 账本里没证 / 证过期 / 档位不含 B | 按 §1.2 重签（注意 env 要和跑脚本时**同一个**）；`--dry-run` 可先查 |
| 退出码 **3** + 原因是「范围不符」 | 证里没有 B（或没有 A） | `--request "A,B,C"` 重签 |
| 退出码 **4** + 「靶场窗口没起来」 | Edge 起得慢/被拦 | 加 `--timeout 40` 重跑；或自己开窗口后 `--no-launch --hwnd <hwnd>` |
| 退出码 **4** + 「抓不到客户区画面」 | Chromium 窗口 PrintWindow 拿不到画面 | 脚本已带 `--disable-gpu`；仍失败 ⇒ 换 `--hwnd` 指向别的窗口再试；**这一档记「未核到」，不要当通过** |
| 退出码 **4** + 「找不到定位色块」 | 页面没画完/颜色被改 | 脚本已重试 12s；仍失败 ⇒ 打开靶场页面对一眼（`file:///…/慢应用靶场.html?ms=300`） |
| 某档 code=**12**（STALE_CAPTURE / wrong_target） | 凭据过期或落点被别的窗盖住 | 脚本每次点击前都重拍凭据；若是 `wrong_target` ⇒ 靶场窗口被压住了 ⇒ 别在它跑的时候操作别的窗口 |
| 某档 code=**9** | 证过期/次数用尽 | 重签 |
| 某档 code=**5**（没测出来） | 画面退化/抓不到帧 | 看 JSON 里的 `退化` 字段；Chromium 抓帧不稳时常见，**记未核到** |
| 某档 code=**8**（该 0 的档） | 慢应用没被救回 | 先排「落点/页面」：看「命中确认」是不是对应按钮；再排「甲案有没有加载」：跑 `--cases slow2 --ms2 900`，看「加长观测」字段出不出现 |
