## 三、真数据抓出的两个真 bug（已修，判据未覆盖到、靠演练抓到）

1. **timeline 的 seq 跨 epoch 重复**（真源 `UNIQUE(seq,hash)` 同 seq 不同 hash 合法）⇒ 旧 schema
   `UNIQUE(src_seq)` 静默吞了 184 条。修：episode 幂等键改 **UNIQUE(src_seq, t)**，
   `add_episode` 去重查 (src_seq, t) 双键。
2. **sqlite-vec 0.1.x 的 KNN LIMIT 硬上限 4096**：全库 7472 条时 `search_episodes` 直接炸。修：
   KNN limit 封顶 4096；带候选集且候选超限时自动回落 numpy 精确路径。

## 四、已知边界与未竟（如实）

- **hash-ngram 嵌入下 MERGE_SIM=0.85 区间很窄**：文本要近乎逐字相同才触发合并（真库 7472 条只合出
  42 个父段）。巩固 v0 主要靠断裂/锚点边界；换语义嵌入模型是后续最大单点收益（embedder 已可插拔）。
- click 的 target 只有坐标（语义目标名在感知层 find/tree 事件里，v0 未做跨事件焊接 = M3 bbox 对齐，
  设计稿 §6.4 空白③）；screen_version 字段已留、待感知层接入。
- obs 检索文本里 xy 出现两次（obs 与 target 各一次），纯噪声不影响命中率，下刀顺手修。
- **接手时发现的既有漂移（未动，待主人裁决）**：`len(CRITERIA)` 接手时实为 64 而三处台账写 52/53；
  另有十余个 `_P2_/_P3_/_codex_` 判据文件既不在 CRITERIA 也不在 NOT_WIRED（元判据的既有红点，
  本次只同步了条数账并补记 54..64 缺账，没有替别的批次接线）。
- episode 库在 `work/memory/episodes.db`（gitignore 区，可随时重建）；时间线全程只读。

## 五、用法

```powershell
$env:PYTHONPATH="<仓根>\src"
python -m agentctl.memory harvest          # timeline → episodes（增量幂等，断点续收）
python -m agentctl.memory compact          # 巩固（幂等）
python -m agentctl.memory distill          # 经验提炼（幂等 upsert）
python -m agentctl.memory query "保存 弹窗" # 检索（episode + 段摘要 + workflow，带出处与三值结局）
python -m agentctl.memory stats            # 库内计数与游标
# 库路径：AGENTCTL_MEMORY_DB 或 <仓根>\work\memory\episodes.db
```
