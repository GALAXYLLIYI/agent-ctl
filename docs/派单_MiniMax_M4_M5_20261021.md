## 统一背景

统一目标：**以最小代价让 agent 具备电脑控制能力，进而实现自动化；只在 GUI 层面做。**

M2（输入归因层）已交付并通过主控独立复核（判据绿 17 / `--inject` 红 5 / `src` 与 `contract` 零改动）。关键结论：

- 本机**能做输入归因**：钩子装得上（**必须 `hMod=NULL`**，传 exe 模块句柄会 err=126）、`LLMHF_INJECTED(0x01)` 读得到、不改写输入（实测位移 [0,0]）
- ★ **必须切 DPI 感知**：本机 150% 缩放下，unaware 进程 `GetCursorPos` 给逻辑坐标 (1510,280)，钩子给物理像素 (2265,420)，**差 1.5 倍**
- 四档判定：agent(0.80) / agent弱(0.60) / 真人(0.90，RDP 下 0.55) / 远程他程序(0.75) / 未知(0.00)；**注入事件永不可达「真人」档**
- 真相源是 `work\timeline\timeline-*.jsonl`，**不是** `timeline.db` 的 events 表

## M4：SendInput 统一带专属 `dwExtraInfo` 魔数

### 0. 一句话目标

> 让每一次 agent 注入都带自己的标记，归因能一票确定「是 agent 做的」，砍掉整类时间邻近误判。

### 1. 结果定义

```
① 魔数常量：在 agentctl 内定义一处（建议 0xA6E17，或你选一个带前缀不易撞的值），
   所有 SendInput 路径统一带上，并写进 docs/AGENT接口.md
② 判据 tests/_P2_魔数_判据.py：
   - agent 产生的事件 dwExtraInfo == 魔数
   - 非 agent 注入的 dwExtraInfo != 魔数（用 --inject 造假事件覆盖）
③ 独立核验记录：改前/改后 MD5 + 复跑判据的原始输出落盘
```

### 2. 边界

- 改动面**只限 SendInput 的 dwExtraInfo 填充**；不许顺手动别的逻辑
- 改真源必须走本仓规矩：**改前备份 + MD5 预检 → 改后独立核验 + 字节级 token diff**
- 判据必须**先红后绿**（先造一个红，再让它绿）
- 不许装依赖、不许起常驻

### 3. 判定口径

| 档 | 定义 |
|---|---|
| 算解决 | 判据先红后绿有记录；md5 前后齐全；魔数在 docs 写明 |
| 不算解决 | 「应该好了」但没复跑判据 / 没留 md5 / 顺手动其它逻辑 |
| 算验不了 | 环境不满足 ⇒ 显式说验不了，不许写绿 |

## M5：归因层落地为库（`src/agentctl/attribution.py`）

### 0. 一句话目标

> 把 M2 的设计变成 agentctl 里一个能直接调用的库，先不碰 contract。

### 1. 结果定义

```
① src/agentctl/attribution.py：按 M2 设计稿实现归因判定（注入位 + timeline 对账 + DPI 感知 + 降级语义）
② 对外暴露方式：**先不加工具进 contract**（A1 硬上限余量仅 149 字符、A3 参数键集冻结，
   加参数必红 A1/A3，改口径须用户点头 ⇒ 本单不碰）
   走 legacy_tools 或独立 CLI，判据从命令行可调
③ 判据 tests/_P3_归因落地_判据.py：四档判定各有可核证据；
   「未知」不得硬猜成「真人」；--inject 变红
④ 跨进程单调钟对齐：用 clock.Clock.session_open()（clock.py:90）落地并验
```

### 2. 边界

- **不许改 `contract/tools.json`**（本单不加工具 ⇒ 不触发 A1/A3）
- 不许起常驻进程；不许读含密钥文件
- 依赖 M4 先落地（没有魔数，归因只能靠时间邻近，误判多）

### 3. 判定口径

同 M4 第 3 节，另加：**「未验」的路径必须显式报验不了**（M2 已如实报「探针窗口内无 agent 动作，0 条候选」）——不许用假事件冒充真命中。
