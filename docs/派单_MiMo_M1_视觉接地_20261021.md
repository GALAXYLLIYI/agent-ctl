## 0. 一句话目标（≤40 字）

> 让 MiMo Code 借 agentctl 拿到本机一个真实窗口的截图，**用眼睛**说出其中一个可点击按钮的名字。

## 1. 结果定义（交付物必须长什么样）

```
① 文件 <工作区>\Documents\2026-10-21\new-chat\work\mimo_probe\probe.json
   必须含字段：
   - picked_hwnd        整数，选中的窗口句柄
   - window_title      字符串，该窗口标题
   - ctl_find_names    字符串数组，ctl_find 命中的可点击控件名字（≥3 个）
   - shot_path         字符串，截图落盘路径（文件必须真实存在）
   - vision_answer     字符串，你**只看图**（不看 ctl_find 结果）时认为的按钮名字
   - agrees            布尔，vision_answer 是否出现在 ctl_find_names 里
② 文件 <工作区>\Documents\2026-10-21\new-chat\work\mimo_probe\shot.png（真实截图）
③ 终端原始输出落盘到 work\mimo_probe\run.log
```

## 2. 判定口径

| 档 | 定义 |
|---|---|
| **算解决** | probe.json 五字段齐全且 shot.png 真实存在；`agrees=true`；且 vision_answer 是**你先看图后写下的**，不是抄 ctl_find |
| **不算解决** | 只把 ctl_find 的结果抄进 vision_answer（那没验证视觉）；或说「已完成」但文件不存在；或字段缺失 |
| **算验不了** | 通行证失效 / 无可用窗口 / MCP 调不通 ⇒ **显式写明缺什么**，不许写绿、不许编数据 |

## 3. 证据要求

- 每个「绿」必须给出盘上真实路径；数字必须能在盘上找到出处
- 「我调用了 ctl_shot」必须附返回里的 capture_id 或帧号
- 失败也要留日志（stderr、错误码原文），不许只报结论
