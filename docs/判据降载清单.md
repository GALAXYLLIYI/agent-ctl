## 三、元判据降级的两个必做连带（不做=降载本身会被判红）

1. **元2 的清点基准要改**：元2 断言"文档写的条数 == len(CRITERIA)"。快车道裁到 6~7 条后，`run_all.py` 的 CRITERIA 与《判据有效性清单》必须同步改写，否则元2 把降载本身判成"判据失踪"。改写规则建议：快车道清单与发布审计清单**各设一节**，元2 改为断言"两清单之并 == 磁盘判据文件集合，无孤儿无幽灵"。
2. **降级 ≠ 放宽**：16 条审计在**每次发布前**必跑且贴回执；`tests\` 有改动的提交，元1/元2 在提交说明里必须引用最近一次审计结果。审计脚本 `tools\release_audit.py` 归后续施工单（本单不建）。
