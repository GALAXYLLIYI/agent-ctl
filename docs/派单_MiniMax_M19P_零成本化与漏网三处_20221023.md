## 二、任务①（零成本化）：预算耗尽路径**不许二次判差**

**问题**：你写的 `_budget_verdict(base_img, last)` 里又调了一次 `_img_diff`。
主控实测（20 次平均、1632×1191 全尺寸帧）：**13.84ms/次** ⇒ 每次「画面没变」的动作多花 13.8ms，
总耗时 450 → **463.8ms**，破坏 `act.py` 自己写的「总耗时 ≤ 预算（永远不慢于改前的固定 sleep）」不变式。

**改法（语义完全不变、零额外耗时）**：

- 循环前初始化 `last_d = None`；
- 每次 `d = _img_diff(base_img, cur)` 之后立刻 `last_d = d`（此刻 `last` 就是 `cur`，`d` 正是 `last` 的判差）；
- `_budget_verdict` 改成**只吃已算好的判差**（不要再调 `_img_diff`）；
- 判据保持完全一致：`last_d` 为 None ⇒ False；`last_d.get('changed') is True` ⇒ None；其余 ⇒ False。

## 三、任务②（漏网三处）：「没测出来」不许写成「确认没变」

ZCode 实锤三处（同族缺陷，**M19′ 修不到**，它们不走 `_wait_effect`，走文件 MD5 指纹）：

| # | 位置 | 现状 |
|---|---|---|
| W1 | `act.py:2594`（do_fill 出口） | `return 0 if changed is True else 8` ⇒ **`changed=None`（指纹取不到＝没测出来）→ rc=8「确认没变」** |
| W2 | `act.py:3353`（do_type focus 段） | 同上 |
| W3 | `act.py:3382`（do_type element 段） | `return 0 if (dry or changed is True) else 8` ⇒ 同上（`dry` 分支不动） |

**改法**：三处都改成三态映射 —— `changed is True` ⇒ rc=0；**`changed is None` ⇒ rc=5（没测出来）**；`changed is False` ⇒ rc=8（确认没变）。

★ **依据**：`core.py:2881` 自己写的铁律 ——「没测出来」与「没变」必须分开；unknown 永不当成功，也**不当「没变」**。
★ **口径提醒**：`rc=5` 在本仓表示「没测出来 / 判不了」，agent 侧会**倾向重试**；`rc=8` 表示「确认没变」，agent 侧不重试。
⇒ 这三处改完，**指纹取不到**就不会再被谎报成「页面没变」。
