## 三、★★ 并行/串行规则（这一单最容易翻车的地方）

1. **静态活随便跑**：读源码、写方案、写测量脚本、跑**不产出计时数字**的命令 —— 互不干扰。
2. **时序实测必须持「测量窗口令牌」**：令牌文件 `work\_M17_解剖_20221022\窗口令牌.txt`，内容三行：`持有者` / `开始ISO` / `结束ISO`。**只允许一个持有者。**
3. **令牌只能向主控要**（主控是唯一发令的）。**不许自己写令牌文件。**
4. **窗口内另外两方不许跑任何带耗时的命令**：不许 `importtime`、不许 UIA 计时、不许跑判据/测量器；只许读码与写文档。
5. **窗口默认 20 分钟**，到点交还；被打断也交还。
6. **静默确认**：每方在窗口外写 `work\_M17_解剖_20221022\静默确认_<A|B|C>.txt`（内容 `静默中 | 起 | 止`）。**要开窗口的人，必须先确认另外两份都是「静默中」**，否则不开始。
7. **主控在窗口期间不持有 agentctl 租约、不抢前台、不跑任何重命令**（M16 那次主控占着租约，把执行者的测量全拒成 code=10，整组作废）。
8. **每份报告必须写**：窗口持有者 + 窗口起止时刻 + 另外两方的静默确认 + n + p50/p95 + 口径。**缺一项 ⇒ 该组数不作数。**
