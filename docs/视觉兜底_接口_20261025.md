# 视觉兜底接口 · 协议（2026-10-25）

> `src\agentctl\vision_assist.py` —— 给「UIA 拿不到时」留的**接口位**。
> ★ 本单**不接模型**：只定协议 + 给一个假后端（不读图、不联网）。
> 验：`python -X utf8 tests\_P3_vision_assist_判据.py`（⇒ exit 0，15 条全绿）／加 `--inject`（⇒ exit 1，4 条红）

## 一、协议（四条，别长）

| 项 | 约定 |
|---|---|
| 开关 | `ENABLED` 默认 **False**；只有 `AGENTCTL_VISION_ASSIST=1` 才开（**导入时读一次** ⇒ 设了要**重启进程**） |
| 后端 | `Backend.locate(image_bytes, target_name, window_rect) -> list[dict]` |
| 候选 | `{"label": str, "bbox": [x, y, w, h], "confidence": float}` |
| 出口 | `locate_safe(...) -> {"ok", "found", "reason", "detail", "candidates"}` |

## 二、结果是**三态**，不是两态

| 状态 | 判定 | 含义 |
|---|---|---|
| 找到了 | `ok=True, found=True` | 有候选（`candidates` 非空） |
| **有效观测到「没有」** | `ok=True, found=False` | 后端正常回答"画面里没这个" ⇒ **不是**没测出来 |
| **没测出来** | `ok=False, reason="unobservable"` | 超时 / 异常 / 候选不合规 / 开关没开 |

★ 「没测出来」与「没有」**必须分开**（M19′ 的教训：把「没测出来」写成「确认没变」会让流程静默停住）。
★ 兜底通道的失败模式最坏：把「不知道」写成「大概是这儿」⇒ **永不当成功**。

## 三、默认关闭的理由

1. 装完就开 = 用户的屏幕被送进一条**没人测过**的通道 ⇒ 不行。
2. 兜底通道最容易把「不知道」说成「找到了」⇒ 点错一个按钮。
3. 开关是**一行 env**，要开随时开；反过来"默认开着"就没有这个选项了。

## 四、隐私边界（默认不发图）

- **默认关闭 ⇒ 图根本不会被交给任何后端**（`locate_safe` 进门就返回 `unobservable`；判据用探针后端证明"调用次数 = 0"）。
- 本模块**不打印、不落盘** `image_bytes`；假后端连调试都不记图像内容（只记调用次数与目标名）。
- 本仓**只提供假后端** ⇒ 结构上**不可能**把图发出去（判据静态断言：源码无 `http(s)://` 字面量、无网络/模型 import、只用标准库）。
- 将来接真后端时：必须在这一层加**显式的人为确认**，且**默认仍不发**。
