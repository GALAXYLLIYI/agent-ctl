## 一、为什么先修这个（主控核过的完整链路）

```
act.py:1353  预算耗尽 => return {生效: False}
              ★ 这里把「我等不起、没机会看到变化」和「我看到了、确实没变」混成了同一个值
   ↓ act 不再轮询，把最后一帧交回
core.py:3305 core 用自己的尺子：before 帧 vs 最后一帧 => 无差异
core.py:2896 changed is False => code=8「确认没变」    ← agent 不重试
core.py:2902 changed is None  => code=5「没测出来」  ← agent 才重试
```

=> **违反 core.py:2881 自己写的铁律**（「没测出来」与「没变」必须分开）。
=> **真实代价**：慢应用（响应慢于预算）被推成 code=8 => **自动化流程停在那里，agent 不会重试**。
=> **这就是「砍预算」的真实代价** —— 砍预算本身不违法，**砍预算前不修这个，才会拿「误判失败」换速度**。
