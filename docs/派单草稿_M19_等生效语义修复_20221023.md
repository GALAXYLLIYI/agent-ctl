## 二之二、★★ 主控终版（M19′）：**只降级「最后一刻有动静」的那部分**

### 为什么不是「一律降级」（M19 粗版）

M19 粗版 = 预算耗尽**一律** False→None ⇒ 「从头到尾画面就没变过」的应用也会被说成「没测出来」
⇒ **信息量损失**：判词不再区分「确实没变」与「没测出来」。

### M19′ 的判据（**改这一处，且只改这一处**）

```
act.py:1353-1357（预算耗尽分支）

改前：
    return {"生效": False, "轮次": rounds, ...}

改后：
    # ★ 本刀：预算耗尽时，区分两种情况 ——
    #   ① 最后一帧与基线**相同** ⇒ 从头到尾没变化 ⇒ 仍判 False（code=8「确认没变」，语义不变）
    #   ② 最后一帧与基线**不同** ⇒ 最后一刻有动静，只是没攒够 need=2 来确认
    #      ⇒ 判 None（code=5「没测出来」）⇒ **agent 会重试**，而不是闭嘴说「没反应」
    _changed = act._img_diff(base_img, last) if last is not None else None
    _saw = bool(_changed and _changed.get("changed") is True)
    return {"生效": None if _saw else False, "轮次": rounds, ...}
```

### ★ 为什么这样改是安全的（关键：不会误报成功）

主控 09:27–09:30 实测过「判 True」那条路（**已否决**，见 `docs\发现_有效预算比名义预算少一轮_20221023.md` §十二）：

⇒ ★ **M19′ 判的是 None 而不是 True** ⇒ **闪烁永远不会被判成功**（None ⇒ code=5「没测出来」⇒ agent 重试，不是成功）。
⇒ ⇒ **M19′ 不动 need=2 这一层设计**，只改「预算耗尽时 act 怎么描述自己的观测」。

## 七之二、★★★ 2026-10-23 01:45 补：主控已把代价量化了，而且**发现的根因比原以为的更深**

### 1. 代价已量化：砍预算 ⇒ 慢应用**整段**掉进「确认没变」

| 响应延迟 | 预算 450ms（现行） | 预算 300ms | 预算 200ms |
|---|---|---|---|
| ≤100ms | 100% 检出 | 100% | 100% |
| **200ms** | **100% 检出** | **0%** | **0%** |
| ≥300ms | **0%** | 0% | 0% |

★ 每个 0% 的格，**被误判成「确认没变」的比例 = 100%**。
⇒ **砍 450→200ms ⇒ 响应 200–300ms 的应用整段从「100% 检出」掉进「100% 确认没变」**。

### 2. ★ 根因不是「应用慢」，是「差一轮」——**这个本单修不掉，得另派**

主控逐轮实测（450ms 预算，第 k 轮起变化）：

| 起变轮次 | 1 | 2 | 3 | 4 | 5 | **6** | 7+ |
|---|---|---|---|---|---|---|---|
| 生效 | True | True | True | True | True | **False** | False |

**机制**：**一轮真实成本 86.2ms**（24ms 抓帧 ＋ **12.2ms diff** ＋ 50ms 间隔）⇒ 450ms ÷ 86.2 ≈ **5.2 轮**
（⇒ 返回轮次封顶在 6）；而 `need=2` 要求变化后**再来一帧**才能确认 ⇒ **落在第 6 轮的变化永远检不到**。
⇒ **名义 450ms ⇒ 可靠覆盖实际只有 ~431ms（5×86.2）**，比名义少约一整轮。

⚠ **★ 09:22 更正（本草稿初版把一轮算成 74ms，漏了 diff 的 10~12ms）**：
主控随后实测出「一轮 86.2ms」，并据 MiniMax 用 `首变图` 判别出的直接证据补上关键一环：

| 起变轮次 | 检出 | **看见过变化** | **连看都没看见** |
|---|---|---|---|
| 5 | 70%（主控 n=6 测到 100%，抖动） | **20/20** | 0 |
| **6** | **0%** | **17/20** | 3/20 |
| 7 | 0% | **0** | **20/20** |

⇒ ★★ **边界轮的失败不是「没看见」，是「看见了，但只有一帧证据，而 need=2 要两帧」**
⇒ ⇒ **本单（语义修复）正是治这个的**：把这些「看见了」从「确认没变」改成「没测出来」⇒ **agent 会重试**。
⇒ ⇒ **本单修完，「可靠覆盖」仍只有 ~431ms**（它不增加检出能力，只增加重试机会）
⇒ **要增加检出能力 ⇒ 是 M20（边界轮「看见即认」，431→517ms，零成本）** ⇒ 本单与 M20 **互补，不重叠**。
