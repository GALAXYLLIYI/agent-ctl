## 一、摘要（5 句，可直接粘贴）

AgentCtl is a Windows desktop action gate that sits between a computer-use agent and the keyboard and mouse, reachable over MCP, HTTP, or a CLI. The gap it closes is that an agent being *able* to click something is not the same as that click being *trustworthy*: an agent can only act on a window a human has authorised, and every action has to leave evidence behind. Three mechanisms carry that difference: a human-issued pass that is time-boxed and count-boxed, a three-state verdict that separates "changed" from "confirmed unchanged" and from "could not be measured", and a local audit trail with a file-level kill switch that stops every automatic action at once. Scope is deliberately narrow: Windows 10/11 only, still 0.x and experimental, default-deny until a human issues a pass, no SLA, and no external users yet. To try it, run `install.ps1` from a clone (or unzip the Release build) and point an MCP client at `http://127.0.0.1:8761/mcp`.

## 五、复用规则（贴出去之前先看这条）

**允许**：删掉不适用的句子、把 5 句拆成三段、按清单要求缩短。

**不允许**：

1. **不许上营销词** —— 「已可上生产」「默认可信」「业界最好」「企业级」「久经考验」「快得离谱」这一类英文原词**一个都不写**（本文件刻意不复写那些词，免得被当可用文案抄走）。它们要么不实（0.x、单人维护、零外部用户），要么不可核。
2. **不许加数字**，除非能在仓内指到行。禁止任何**查不到出处**的性能/规模数字（例如「多少名裁判打分」「比某个 A/B 方案快百分之几十」这种）。目前允许对外说的数只有：**三态出口码 0 / 8 / 5**、**通行证默认 30 分钟 / 60 次**（可配置，非承诺）、**0.x 版本号**。
3. **把实验性说成稳定** —— 不许删掉 `0.x` / `experimental` / `no SLA`，也不许把「暂无外部用户」改成「已被广泛使用」。
4. **暗示它替你判断对错** —— 证据链只证明「发生了什么」，不证明「这应该发生」（`README.md:220`）；动作正确性不是它保证的东西。
5. **暗示它能绕风控 / 验证码** —— 项目明确不做（`README.md:208-209`）。
