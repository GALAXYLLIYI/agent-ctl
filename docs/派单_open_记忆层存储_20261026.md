## 任务

1. `src\agentctl\memory\embedder.py` —— 总单 §四 的 `HashNGramEmbedder`（NAME 常量、dim、embed）。
2. `src\agentctl\memory\store.py` —— 总单 §五 的 `MemoryStore` 全部方法。

实现要点：
- schema 一律执行 `contract.SQL_SCHEMA`，不许另写 DDL；常量只从 `agentctl.memory.contract` import。
- sqlite_vec 路径：`conn.enable_load_extension(True)` 后 `sqlite_vec.load(conn)`；建 vec0 影子表
  `vec_episodes(a float[{EMBED_DIM}])`，rowid=episodes.id，add 时同步写入；加载失败 ⇒ 自动落 numpy 路径。
- numpy 路径：懒加载全库 embed BLOB 为 float32 矩阵（行存 id 对齐），点积即余弦（向量已 L2 归一；
  防零向量除零：范数<1e-12 的向量相似度记 0）。
- 幂等：`add_episode` 对已存在 src_seq 直接返回既有 id（INSERT OR IGNORE 后查 lastrowid/再查 id）。
- 自证脚本 `work\_记忆层_20261026\自证_存储层.py`（参照总单 §三导入口径），断言至少：
  ① schema 建立、meta 读写；② 同文本两次 embed 全等（跨实例）且 L2 范数=1（±1e-6）；
  ③ add 幂等（同 src_seq 两次 → 1 行、返回同 id）；④ 50 条干扰 + 1 条针，query 命中针且相似度显著高于干扰均值；
  ⑤ dim 不符 pack_vec 抛 ValueError；⑥ 两条路径（use_sqlite_vec=True/False）检索结果一致（同序同分±1e-4）；
  ⑦ pyflakes 零致命。**自证 DB 一律放 %TEMP%。**
