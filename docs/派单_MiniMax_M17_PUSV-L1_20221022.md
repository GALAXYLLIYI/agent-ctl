## 0. 一句话

把论文的 **PUSV-L1**（**动作前**再验一次 UI 状态）本地化到本机：
**点击落地前**，把「落点那一小块」和「观测时那一小块」比一次，变了就拒。
⇒ 堵住 **TOCTOU**（观测之后、动作之前，界面被人改了）。

## 1. 论文原文要点（ZCode 已核，**照抄别改**）

- PUSV = **Pre-execution UI State Verification**，**动作前**的再验证（**不是**为省动作后等待设计的）。
- 三层：**L1 = 点击目标处 masked pixel SSIM**；**L2a = 全局截图 diff**；**L2b = X Window 快照 diff**。
- 开销 **< 0.1s**；180 次对抗试验 **100% 拦截、零误报**。
- ★ **任何单层都不够**（不同攻击原语要不同信号）⇒ **要分层**。
- ★ **论文自承的盲区**：纯视觉防不住**零视觉痕迹的 DOM 注入**。

## 2. 本机落法（**只做 L1**，L2a/L2b 本轮不做，写进文档挂账）

本机已有现成件，**不用新造**：

- `core` 里的 `_bind_capture`（现成 `verify_image`）：现在是**全窗 SHA-256 全等**（太脆，一像素变就拒）；
- `framecache.STORE`：TTL 内的观测帧；
- `perceive.grab_client`：抓客户区。

**形状（ZCode 给的伪代码，按本机现码改写）**：

```python
rec = framecache.STORE.get(cap_id, hwnd)      # TTL 内的观测帧
r   = 64                                        # 落点邻域半径
new = grab_client(hwnd, rect=client_rect_around(xy, r))   # 小 DC，只抓 128×128
old = crop_client(rec.img, client_rect_around(xy, r))
if mad_gray(new, old) > MAD_THRESH:
    return GateDenied(code=12, "TOCTOU：落点区域已非观测帧，重新观测再点")
```

⚠ **坐标系必须与落点 xy 同源**（contract 的 conventions：物理像素、屏幕坐标）⇒
邻域的裁剪矩形要按**客户区 origin** 换算，别用截图内坐标。

## 3. 附带提速价值（**只对声明了 verify_expect 的动作生效**）

动作后等待的 budget 可以**折半**（因为「期望」已声明 ⇒ 只需确认期望达成，不必确认任意变化）。
⚠ **不许**推广到没声明谓词的动作（那会变成「不确认就当成功」⇒ 破铁律）。

## 4. 判据（**搬论文指标，本地化**；**先红后绿**）

1. **拦截率 100%**：构造「观测后改落点再点」⇒ 必须被拒（code=12）；
2. **零误报**：静止桌面 **50 次**动作 ⇒ **0 次**被误拒；
3. **开销 ≤100ms**（本机预期 20~40ms）⇒ 断言实测在界内；
4. **盲区如实登记**：DOM 注入（零视觉痕迹）**拦不住** ⇒ 判据里要有一条
   「说明这一项拦不住」的显式记录，**不许假装拦住了**。

## 5. 红线

1. **不许改 `contract/tools.json`**；**不许改 `gate.py` 的授权口径**；**不许改任何 code 数值语义**。
