**为什么是这 4 处、这样改最安全（三条）**：

1. **判词仍然只有 core 一把尺子**：`_picture_verdict`（`core.py:2873`）的**签名与语义一个字都不动**（它被 `tests\_P2_M12_等待合并_判据.py:533` 直接按 2~3 个位置参数调用，改签名会让那条判据当场 TypeError）。加长观测只在**它之前**把 `_df` 换掉，不碰它。
2. **触发条件收窄到「一格」**：core 的判词表里，**只有** `df.changed is False` 这一格会落到 code=8（见 §一 表）。甲案**只在这一格**加观测 ⇒ 其余四格（成功 / 退化 / 没测出来 / act 前置拒绝）**零改动、零等待**。
3. **加长观测放在判决层（`_act` 内），不是取帧层（`_act_after`）**：`_act_after` 跑在 `_act_diff_of` **之前**，它**还不知道**末帧是否==基线；要在那儿判就得**重算一次判差**（+13.8ms，正是 M19′ 刚修掉的那个坑）。放在判决层则 `hwnd` / `_before` / `_after` / `_df` / `_before_off` / 忽略口径**全在手边**，且能把 `_after` 与 `_df` **一起换掉** ⇒ 落盘证据与判词**始终一致**。

### 1.3 判词是怎么产生的（`_picture_verdict`，`core.py:2873-2906`）

| 输入 | 判词 | 信封 code | 备注 |
|---|---|---|---|
| `r["ok"]` 为假（act 前置拒绝 rc=4/5/7/9） | 原样返回 | act 的码 | `core.py:2885-2886` |
| `degraded=True` | 没测出来 | **5** | `core.py:2887-2892` |
| `df.changed is True`（末帧≠基线） | 成功（原样返回） | **0** | `core.py:2894-2895` |
| `df.changed is False`（末帧==基线） | 确认没变 | **8** | `core.py:2896-2901` |
| `df.changed is None`（没测出来） | 没测出来 | **5** | `core.py:2902-2906` |

> ★ **这张表就是甲案的落点依据**：
> 「末帧==基线 ⇒ code=8」是**唯一**通往 code=8 的格子，也是**唯一**慢应用会被冤判的格子。
> ⇒ **甲案只在这一格加一次观测**；成功格、退化格、没测出来格**一个字都不用动**。

### 1.4 「末帧==基线」这一格到底怎么来的（为什么慢应用会掉进去）

act 侧（`legacy_tools\_src\act.py`）：

- `_wait_effect`（`act.py:1384`）轮询到**连续 2 帧**（`POLL_HYSTERESIS=2`）超阈才判生效；预算 `POLL_BUDGET_MS=800`（`act.py:1115`）。
- `_emit_effect`（`act.py:1446`）回传 `首变图 or 图`（`act.py:1476`）—— **看到过变化就回传变化那一帧，没看到就回传最后一帧**；payload 只有**十键**（`act.py:1458-1471`），**没有「生效」**。
- ⇒ core 拿到的帧有两种：① **变化帧** ⇒ `_act_diff_of` ⇒ changed=True ⇒ **code=0**（这格本来就没事）；② **最后一帧（==基线）** ⇒ changed=False ⇒ **code=8** ← **慢应用掉进的就是这一格**。

慢应用掉进这一格的**两条真实入口**（core 侧都读得到）：

| 入口 | 现象 |
|---|---|
| **act 预算耗尽**（800ms 内没凑够连续 2 帧） | act 回传最后一帧（==基线）⇒ core 判 code=8。响应更慢的应用落这里 |
| **core 回落 `wait_change`**（`core.py:2957-2959`，**预算只有 300ms**） | act 回传不可用（解析失败 / 口径对不上）⇒ core 自己等 300ms ⇒ 末帧==基线 ⇒ code=8。**响应 300~500ms 的应用必然掉进这一格**（300ms 窗口不够） |

⇒ 甲案要救的正是这两条；而 **core 这条 300ms 的回落窗口，正是「慢应用被冤判」的主要产地**（`core.py:2958` 的 `budget_ms=framecache.WAIT_BUDGET_MS`=300）。

### 1.5 其它相关调用点（甲案**不碰**，列出来是为了确认零影响）

- `_map_rc`（`core.py:2439`）：调用点 `3249`（`_act` 内）、`3519`（`_ask_then_retry`）、`4965`（`t_browser`）—— **只翻 act 的 rc，不参与画面判定** ⇒ 甲案不碰。
- `_act_diff_of`（`core.py:2822`）：调用点只有 `3305` / `3347` ⇒ 甲案**不改它的签名与语义**，只在它之后换掉返回值。
- `_act_after`（`core.py:2930`）：调用点只有 `3303` / `3337` ⇒ 甲案**不改它**（理由见 §〇 第 3 条）。
- `failure_class`（`core.py:1375-1392`）：`_REJECTED_ENV_CODES = {3,4,5,7,9,10,11,12,13}`（`core.py:1370`）、`_NO_EFFECT_CODES = {8}`（`core.py:1372`）⇒ **code=5 属「环境性拒绝」（不计入 fail_streak）、code=8 属「没生效」（计入）**。

```python
def _act_extend_observe(hwnd: int, before, after, df: dict, win_off=None,
                        ignore=None, degraded: bool = False,
                        budget_ms: int = ACT_EXT_OBSERVE_MS) -> dict:
    """★ M20（甲案）· **加长观测**：判「确认没变」之前，core 用**自己的尺子**再看一会儿。

    ★ 触发条件（**收窄到一格**）：`df.changed is False`（末帧==基线 ⇒ core 会判「确认没变」）
      **且** 本次观测**没测出退化**（degraded=False）。
      · `changed is True`（末帧≠基线 ⇒ 成功路）⇒ **不进来** ⇒ **零额外等待**；
      · `changed is None`（没测出来）⇒ **不进来** ⇒ 保持 code=5；
      · 退化 ⇒ **不进来** ⇒ 保持 code=5。
    ★ 期间测到变化 ⇒ 返回新的 (after, df)（changed=True）⇒ 上层照常判成功（code=0）。
      一直不变 / 抓不到帧 / 口径对不上 ⇒ **原样返回** ⇒ 仍判 code=8
      （「确认没变」语义一点没丢，**绝不**变成「一律 code=5」）。
    ★ 尺子**同一把**：`framecache.wait_change` 用的是 `framecache.diff_images`
      （= `_act_diff_of` 的算法本体，`framecache.py:482`）⇒ 不会出现「core 说变了、act 说没变」。
      滞回 `HYSTERESIS=2`（**连续 2 帧**超阈才报变，`framecache.py:80` / `:632-662`）
      ⇒ **闪烁永不被判成功**（抗假阳性红线守住）。
    ★ 返回 {"after":…, "df":…, "观测":{…}}；`观测["做了"]` 为 False ⇒
      调用方**一个字段都不加**给回执 ⇒ 未触发时输出**逐字节不变**。
    """
    _obs = {"做了": False, "原因": "", "耗时ms": 0.0, "轮次": 0, "结果": None}
    _out = {"after": after, "df": df, "观测": _obs}
    if degraded:
        _obs["原因"] = "画面退化 ⇒ 没测出来 ⇒ 不加长观测（保持 code=5）"
        return _out
    if (df or {}).get("changed") is not False:
        _obs["原因"] = "末帧≠基线（或没测出来）⇒ 不加长观测（零额外等待）"
        return _out
    if before is None or after is None:
        _obs["原因"] = "没有基线帧/末帧 ⇒ 无从比对 ⇒ 不加长观测"
        return _out
    _ig = ignore if isinstance(ignore, dict) else ACT_DIFF_IGNORE_DEFAULT
    try:
        r = framecache.wait_change(int(hwnd), before,
                                   budget_ms=int(budget_ms),
                                   poll_ms=framecache.WAIT_POLL_MS,
                                   caret_px=int(_ig.get("caret_px", 8) or 0),
                                   min_area_px=int(_ig.get("min_area_px", 24) or 0))
    except Exception as e:
        _obs["原因"] = "加长观测异常：%s: %s" % (type(e).__name__, e)
        return _out
    _obs["做了"] = True
    _obs["耗时ms"] = float(r.get("耗时ms") or 0.0)
    _obs["轮次"] = int(r.get("轮次") or 0)
    _obs["结果"] = r.get("changed")
    _obs["说明"] = r.get("说明") or ""
    if r.get("changed") is not True:
        _obs["原因"] = "窗口内没有测到变化 ⇒ 判词不动（仍 code=8「确认没变」）"
        return _out
    _img = r.get("图")
    if _img is None:
        _obs["原因"] = "测到变化但没拿到帧 ⇒ 判词不动"
        return _out
    # ★ 口径守卫：尺寸不同 ⇒ `diff_images` 会**直接判 changed=True**
    #   （`framecache.py:515-519`「动作前后画面尺寸变了」）⇒ 那是**假成功** ⇒ 这里不升级。
    try:
        if before.size != _img.size:
            _obs["原因"] = ("新帧与基线口径/尺寸不同（%s vs %s）⇒ 不升级"
                            % (before.size, _img.size))
            return _out
    except Exception:
        _obs["原因"] = "取不到基线尺寸 ⇒ 不升级"
        return _out
    _new_df = _act_diff_of(before, _img, win_off, ignore)
    if (_new_df or {}).get("changed") is not True:
        _obs["原因"] = "复核判差未确认变化 ⇒ 判词不动"
        return _out
    _out["after"] = _img
    _out["df"] = _new_df
    _obs["原因"] = "窗口内测到变化 ⇒ 改判成功（code=0）"
    return _out
```

**替身骨架（施工者可直接照抄）**：

```python
class FakeTime(object):
    """S1 替身：装到 `framecache.time` 上（framecache 用 perf_counter / sleep / time）。"""
    def __init__(self, t0=0.0):
        self.t = float(t0)
        self.sleeps = []
    def perf_counter(self):
        return self.t
    def sleep(self, sec):
        self.sleeps.append(float(sec))
        self.t += float(sec) * 1000.0
    def time(self):
        return self.t / 1000.0


class FakeEnv(object):
    """假时钟 + 假抓帧 + 假判差计时（**不碰真窗口**）。"""
    CAPTURE_MS = 24.0     # 本机实测客户区 PrintWindow（framecache.py 头注）
    DIFF_MS = 12.2        # M19 判据同口径（tests\_P3_M19_语义修复_判据.py:55）

    def __init__(self, script):
        self.clock = FakeTime()
        self.script = script        # list[Image|None] 或 callable(i)->Image|None
        self.n_capture = 0
        self.n_diff = 0
        self._real_diff = framecache.diff_images

    # ── S2 替身：`(hwnd:int) -> Image|None`
    def capture(self, hwnd):
        i = self.n_capture
        self.n_capture += 1
        self.clock.sleep(self.CAPTURE_MS / 1000.0)
        if callable(self.script):
            return self.script(i)
        return self.script[i] if i < len(self.script) else None

    # ── S3 替身：`(before, after, **kw) -> dict`（转调真判差）
    def diff(self, before, after, **kw):
        self.n_diff += 1
        out = self._real_diff(before, after, **kw)
        self.clock.sleep(self.DIFF_MS / 1000.0)
        return out

    def install(self):
        """装桩；返回还原函数（必须在 finally 里调）。"""
        _old_time, _old_cap, _old_diff = (framecache.time, framecache.capture_client,
                                           framecache.diff_images)
        framecache.time = self.clock
        framecache.capture_client = self.capture
        framecache.diff_images = self.diff
        def restore():
            framecache.time = _old_time
            framecache.capture_client = _old_cap
            framecache.diff_images = _old_diff
        return restore
```
