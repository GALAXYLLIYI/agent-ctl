# 工单 · minicode · agentctl 动漫风图标设计+接线 · 2026-10-27

> 背景：托盘/面板现在用的是 Windows 默认图标（tray.py:141 `LoadIconW(None, IDI_APPLICATION)`），
> 面板窗也没有 iconbitmap。用户要求：**整个动漫风**。
> 台账：`work\_长任务_20261027\台账.md`（先读）。

## 任务（三件）

### ① 设计动漫风图标原图
- 优先路线：`mmx image generate`（MiniMax CLI，已登录）生成 **动漫风** 原图。
  提示词方向：可爱动漫风吉祥物，一只大眼睛的机械小卫士（大动漫眼+高光），深蓝底色+青色霓虹高光，
  简洁剪影、居中构图、纯色/透明背景，正方形。生成 2-4 张候选，选最清晰的。
- 兜底路线（mmx 失败/配额尽）：PIL 画简化的动漫风脸（圆脸+大眼+高光+腮红），够 16px 可辨即可。
- **硬要求：16×16 下轮廓仍可辨认**（简洁 > 细节）。

### ② 后处理打包（PIL）
- `tools\make_icon.py`：原图 → 居中裁方 → 生成 16/24/32/48/64/128/256 七档 → 打包
  `assets\agentctl.ico`（多尺寸单文件）+ `assets\agentctl_64.png`（Tk iconphoto 用）。
- assets\ 目录新建并确认进 .gitignore 白名单（加 ⑰ 条目：图标资产必须进仓）。

### ③ 接线（小改，不许大动）
- `src\agentctl\tray.py`：`LoadIconW(None, IDI_APPLICATION)` 处改为优先
  `LoadImageW(None, <assets\agentctl.ico 绝对路径>, IMAGE_ICON, 0, 0, LR_LOADFROMFILE)`，
  **失败回退 IDI_APPLICATION**（图标缺失不许崩）；路径用 `os.path.join(repo_root, 'assets')` 推导。
- `src\agentctl\widget.py`：面板窗 `root.iconbitmap(<ico>)`（Tk 原生支持 ico），失败安静跳过。
- `tools\launch_agentctl.py`：无需改（图标随文件在即可）。
