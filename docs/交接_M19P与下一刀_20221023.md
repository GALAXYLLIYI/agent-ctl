## 二、★ 头号发现：M19′ 是**空刀**（这是接手前必须知道的第一件事）

**结论**：M19′ 落地正确、红线零违反，但 **agent 拿到的退出码一个字没变**。

```
act 改三态 生效 ──✗── 到不了 core
                   （payload 十键里没有「生效」；core.py 里「生效」0 处代码引用）
core 用**自己的**尺子判（before 帧 vs 最后一帧）：
   末帧≠基线（看到过变化只是没凑够 need=2）⇒ code=0 成功   ← 本来就没事
   末帧==基线（真没变 / 慢应用）        ⇒ code=8「确认没变」 ← 慢应用卡在这
```

| 证据 | 来源 | 结论 |
|---|---|---|
| 合成判决测试 | 主控亲跑 `core._picture_verdict` | `df.changed=False⇒8`；把 `生效=None` 塞进 effect payload ⇒ **仍是 8** |
| payload 枚举 | 窗口A 独立复核 | `_emit_effect` 十键**不含 `生效`** |
| grep | 主控亲跑 | `core.py` 里「生效」**0 处代码引用** |

⇒ **真正的下一刀在 core 侧**（要么 core 多看一眼，要么 core 采信 act 的三态）。

### ★★ 方法论第六条（务必继承）

> **改一个字段之前，先确认「谁读它、读到之后干什么」——没人读 ⇒ 改它等于没改（空刀）。**
> 「语义更诚实」≠「行为变了」；行为链必须**逐跳**核到 agent 拿到的那个字节。

### 3.4 【提速方向】还没拍板的那件（用户已看过决策单 §九.2）

★ **社区结论支持「定向」不支持「全局」**（Playwright 官方）：timeout 的语义是「预期观测没在窗口内到达」⇒
