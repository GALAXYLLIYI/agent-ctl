## 三、每个点必须记的六个字段（少一个，归因就错）

```python
{"tag": "...", "mono_ns": time.monotonic_ns(), "pc_ns": time.perf_counter_ns(),
 "proc_ns": time.process_time_ns(), "wall": time.time(), "pid": os.getpid()}
```

1. **`mono_ns` 与 `proc_ns` 都要**。⑤ 若 wall 涨 450ms 而 proc 只涨 30ms ⇒ 那是 `sleep` 等界面；proc 涨 200ms ⇒ 是 `PrintWindow`/numpy 在烧 CPU。**只看墙钟分不开这两件事**。
2. **`atexit` 落盘**（act 有大量 `return` 分支：拒绝/异常/超时；只在正常出口写会把被拒样本全丢掉）。
3. **不许开 `AGENTCTL_PROFILE=1`**：`act.py:1072` 用了未导入的 `tempfile`（全文无 `import tempfile`），一开就 `NameError`。**用自己的探针文件 + 独立开关**（例如 `AGENTCTL_M17C1_PROBE`）。
