## 二、幻觉（我们今天在治的病，外部依据）

| 论文 | 一句话 | 对我们的用处 |
|---|---|---|
| **HumbleBench（Measuring Epistemic Humility）** [arXiv:2509.09658](https://arxiv.org/abs/2509.09658) | 给「以上都不对」选项时，最强模型也只有约一半敢选 | **支持我们的 rc=2「验不了」一等公民**——不敢说就是不敢说 |
| **RH-AUC / RH-Bench** [arXiv:2505.21523](https://city.engins.org/external/benchmarking-hallucinations-new-metric-tracks-where-multimodal-reasoning-models-go-wrong/view/) | **思维链越长，幻觉越多** | 直接相关：我们常开高推理档 ⇒ 该按任务降档 |
| **SHALE**（中科院+华为） [arXiv:2508.09584](https://arxiv.org/pdf/2508.09584.pdf) | 忠实性幻觉 vs 事实性幻觉两类 | 可作为「判词必须指到证据」的分类依据 |
| **多模态幻觉评测综述** [arXiv:2507.19024](https://arxiv.org/abs/2507.19024) | 40 页综述 | 想系统读从这篇进 |
| **HALLUCINOGEN** [arXiv:2412.20622](https://www.arxiv.org/abs/2412.20622) | 幻觉攻击（诱导说图里没有的东西） | 我们的判据该加一条「不许说图里没有的」 |

## 四、我的判断（写给未来的自己/别的 agent）

```
① 真正能马上用的只有 2 篇：RegionFocus（放大可疑区域 + 图上画决策）、Common-O（相似物体放大幻觉）
② 我们比这批论文多走的一格：**带证据 + 带判据 + 带验不了**。
   论文给"模型能力"，我们给"可核账"——所以这些论文**不能照抄来提升准确率**，
   只能用来解释"为什么必须留证据"。
③ ScreenSpot-Pro 是这一行的通行标尺（密集桌面），
   我们的判据 25/26/27（帧过期/输入判词/体检）本质是在同一方向上自建，
   但没有外部基准数字 ⇒ 想对标就得先能跑 ScreenSpot-Pro。
```
